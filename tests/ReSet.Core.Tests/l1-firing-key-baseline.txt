# 「0 이 목표」가 분명하므로 상한만 잠근다.
#
# ReSet.Core/Services/MechanicalValidator.cs=37 인 이유(2026-09-09 실측):
# `perl -pi -e 's/result\.Errors\.Add\(/result.Report(/g'` 를 97 자리에 돌리자
# `dotnet build --no-incremental` 이 37 곳에서 CS1061 을 냈다 - `StepValidationResult`
# (12213 행)에는 `Report` 메서드가 없다. 이 타입은 `[CallerMemberName]` 통로가 없는

# 구문 트리만 보므로(변수 타입을 모른다) 이 37 곳도 `<무엇>.Errors.Add(...)` 모양이라
# 똑같이 위반으로 잡는다 - 오탐이 아니라 스캐너의 관할 밖(다른 타입)이다.
# 이 37 곳은 손으로 `result.Errors.Add(` 로 되돌렸다(빌드 오류 CS1061 위치 그대로).
