## 0. 무엇이 고장인가

`MechanicalValidator.CleanseMermaidCode` 규칙 1(`:6284~6286`)이 엣지 레이블의 **큰따옴표를
무조건 벗긴다.** mermaid 는 레이블에 `(` 같은 특수문자가 있으면 따옴표를 요구한다.
노드 레이블에는 **씌우는** 규칙이 있는데(규칙 4, `:6337~6355`) 엣지에는 없고 오히려 벗긴다.

`mmdc` 11.16.0 에 직접 물려 갈랐다:

| | 입력 | 결과 |
| :--- | :--- | :--- |
| A | `N005{"…"} -->\|일치 행 없음 (0행)\|N008["…"]` | **Parse error** |
| B | `N005{"…"} -->\|"일치 행 없음 (0행)"\|N008["…"]` | **컴파일 성공** (11,073B SVG) |

**정화기가 B 를 A 로 바꾸고, 그 A 를 컴파일한다.**

### 0-1. 모델은 올바르게 쓴다 — 증거는 지워지지 않았다

동료가 「정화본이 원문을 치환하므로 『모델이 안 썼다』와 『썼는데 벗겨졌다』를 원리적으로
구별 못 한다」고 했는데, **`docs/Thinking.md` 에 정화 전 출력이 남아 있다.**

```
output/Functions/dbo.UF_GET_PGCommOption/docs/Thinking.md
    RowCheck -->|"아니오 (무결과)"| NoAssign["대입 미발생, …"]
                 ↑ 모델이 따옴표를 썼다
```

배송본 `Spec.md` 전량에서 엣지 레이블 **280 개 중 따옴표 있는 것은 0 개**다.
**모델이 안 쓰는 것이 아니라 도구가 벗기는 것이다.**

## 1. 무엇으로 바꾸는가

규칙 1 의 세 정규화가 `-->|텍스트|` 를 만든 **뒤**, 텍스트에 특수문자가 있으면
`-->|"텍스트"|` 로 씌운다. **규칙을 걷어내지 않는다** — 그것이 사 주는 화살표 모양 보정
(`-- 텍스트 -->` → `-->|텍스트|`)은 그대로 살려야 한다.

판별자는 규칙 4 가 노드 레이블에 이미 쓰는 집합 `( ) [ ] { } , ' : - > < / \ @` 이고,
**사본을 만들지 않고 공용 헬퍼로 승격해 둘이 같은 자를 쓰게 한다** — 갈라지면 「노드는
되는데 엣지는 안 되는」 상태가 조용히 생긴다.

**곁들여 닫는 것**: 현행 규칙 1 은 레이블에서 하이픈을 **무조건** 지운다
(`Replace("-", "")`). 따옴표를 씌우면 하이픈이 안전하므로 씌우는 경우엔 지우지 않는다.
지금은 `1-5 범위` 가 `15 범위` 가 되는 **내용 훼손**이라 같은 뿌리다.

## 3. 단위 시험 여섯 (TDD — 빨간 것을 먼저 눈으로 본다)

1. 괄호 있는 무따옴표 엣지 레이블에 따옴표가 씌워진다
2. 이미 따옴표가 있는 엣지 레이블이 **보존된다**(현행은 벗긴다)
3. 하이픈이 **보존된다**(현행은 지운다 — `1-5` → `15`)
4. 특수문자 없는 레이블은 현행대로 **무따옴표**로 남는다(불필요한 변화를 만들지 않는다)
5. **`-- 텍스트 -->` 정규화가 여전히 산다** — 규칙이 조용히 사 주던 것을 안 잃는다
6. 노드 레이블(규칙 4) 동작이 불변이다

## 4. 되돌림 조건

- **R1** — 31 블록 중 **하나라도 새로 부서지면**(기준선 통과 → 새 정화 실패) 되돌린다.
- **R2** — 실패 3 이 **하나도 안 고쳐지면** 재료가 안 닿은 것이니 되돌린다.
- **R3** — 단위 시험 여섯 중 **5·6 이 옛 구현에서도 빨갛다면** 내가 사 주던 것을 잘못
  짚은 것이니 판별자를 다시 세운다(그 둘은 **양쪽에서 초록**이어야 옳다).

## 5. 이 변경이 보증하지 않는 것

- **재생성으로 이 셋이 실제로 통과할지는 모른다.** 이 측정은 **이미 배송된 텍스트**에
  새 정화를 걸어 본 것이다. 다음 재생성 때 모델이 다른 다이어그램을 쓸 수 있다.
- **mermaid 를 L1 재시도 예산에서 떼는 일(§8-2)은 안 한다.** 이 고침 뒤에 그 예산이
  아직도 타는지를 다시 재고 결정한다.
- **31 은 배송본의 블록 수**이지 재생성 회차에 만들어진 다이어그램 전량이 아니다.
- 배송본의 mermaid 는 **이미 정화를 한 번 지난 텍스트**다. 「옛 정화를 다시 걸면 기준선과
  같다」(멱등)를 함께 확인해 이 비교가 성립하는지 본다.
