### 0-4. 쓰기를 섹션 코드에 귀속하는 전제

판본 444 의 제어 합계 INSERT 에서 `StepCode` 자리 리터럴을 셌다: 단계 판본은 자기 코드 18 · 매개변수/없음 13 · **다른 단계 코드 0**(걸린 둘 — B15 S18 · B16 S12 — 은 선행 체크포인트 `IN` 목록이었다). 검증 세트만 단계 몫으로 쓴다(B12 → S17 · B16/B19 → S12) — 세트판 규칙 ①이 다룬다. **단계판에서 「소유자가 쓰는 이름 = 소유자 섹션의 쓰기」 전제는 유지된다.**

## 1. 규칙

기존 ①~④ 는 그대로 두고, ⑤ 옆에 **⑥ 일부 겹침**을 더한다. 한 읽기(몫 `O` = `StepCode` 리터럴 집합, 이름 `R`)에 대해:

1. **몫 전부를 안다** — `O` 의 모든 단계가 「앎」(`OwnerNamesOrNull` ≠ null). 하나라도 모르면 침묵(빠진 이름이 그 단계 몫일 수 있다). `W` = 그 단계들이 쓰는 이름의 **합집합**(B11 S20 은 `IN (N'S13', N'S20')` 으로 읽고 이름은 S20 몫이다 — 몫마다 따로 빼면 거짓 고발한다).
2. `R ∩ W ≠ ∅`(비었으면 ⑤ 의 일이다) 이고 `M = R \ W ≠ ∅`.
3. `M` 의 이름마다 **문서 어디에서도 쓰이지 않는다** — 단계들의 「앎」 쓰기 이름 전체와 검증 세트의 리터럴 쓰기 이름(세트판) 어디에도 없다. 남은 것만 `M′`.
4. 문서에 「모름」 쓰기가 **하나라도** 있으면, `M′` 의 이름이 **읽는 쪽 섹션 밖의** 비 SQL 펜스에 인용 리터럴로 나오면 뺀다(헬퍼 호출 자리). 읽는 쪽 자신의 의사코드는 보지 않는다(§0-3).
5. 문서에 런타임 이름 조합이 있으면 **통째로 침묵**(세트판 안전판 ③과 같다).
6. `M′ ≠ ∅` 이면 발화. 귀속·어휘는 ⑤ 와 같다 — 단계판은 읽는 단계(공통 규약이 빠진 이름을 담고 쓰는 이름을 안 담으면 쓰는 단계), 세트판은 세트 원문 줄(골격 패치 수리).

**문구**: 겹친 이름 · 빠진 이름 `M′` · 소유자가 쓰는 이름 `W` 를 **전부** 싣고, 「이 이름들은 어떤 단계도 쓰지 않아 어떤 실행에서도 행이 없습니다 — 쓰는 이름으로 맞추거나 읽기에서 빼십시오」. 금지 어휘를 백틱으로 싣지 않는다(작성 계약 9). ⑤ 와 **같은 읽기에 둘이 동시에 나는 일은 없다**(2 의 조건이 배타적이다).

**하지 않는 것**: `R ⊆ W`(정당한 부분 비교) · 이름을 모르는 읽기 · MERGE · 파싱 실패. 틀리는 방향은 계속 「덜 보고한다」.

**캐시 버전**: 프롬프트 불변 · L1 만 조인다 → 올리지 않고 P9 의 스윕 차분을 근거로 적는다. main 값 22.
