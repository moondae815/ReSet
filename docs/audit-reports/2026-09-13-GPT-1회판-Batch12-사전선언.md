## ⚠ 기계 검사가 못 잡은 배송 결함 — 또 Critic 만 잡았다

`S03` 의 기지급 사전 점검(`SQL_PRECHECK_SETTLED`)에 **원본에 없는 `PLTID = 1`** 이 붙었다.

```
원본 UP_Util_PG_Client_CMRate_Ins 20~24행      IF EXISTS(SELECT PLTID FROM TSettleMst WITH(NOLOCK)
                                               WHERE YMD = @pi_strYMD AND OutState IN (1,5) AND OutYMD IS NOT NULL)
이행 POQSettleBatch12/S03 167행~                SELECT 1 FROM … TSettleMst WHERE PLTID = 1 AND YMD = @p_ymd AND OutState IN (1, 5) AND OutYMD IS NOT NULL
```

PLTID 가 1 인 행만 보게 되어 **기지급 차단이 사실상 꺼진다.** 같은 가드를 가진 다른 판(Batch8·10·11)은 0 곳이다.
**가설(재지 않았다)**: 명세서 CRUD 표가 이 `IF 1` 행의 컬럼 칸에 `PLTID, YMD, OutState, OutYMD` 를 함께 적어, SELECT 목록 컬럼(PLTID)을
조건으로 오독했다. 기계 검사가 조용한 것은 알려진 한계다 — 원본에 없는 술어를 보는 검사 C 는 `IF EXISTS` 가드를 재료로 갖지 않는다
(`MechanicalValidator` 의 검사 C 주석 「가드 자체가 재료에 없다」). 1 회 판이라 Critic 지적을 고칠 시도가 없었다.
