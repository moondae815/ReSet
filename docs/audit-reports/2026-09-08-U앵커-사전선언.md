## 0. 공통 규율

- **빌드·테스트는 이 격리 워크트리에서만.**
- **게이트는 파일로 받고 `$?` 를 직접 찍는다** — 파이프에 걸면 `tail` 의 종료 코드를 본다
  (2026-09-08 T36 회차에 빨간 게이트를 커밋한 자리).
- **발화 수를 판정으로 쓰지 않는다. 새 발화는 전부 열어 본다.**
- **숫자를 맞추려고 아래 조건을 손보지 않는다.**

## 1. 무엇을 고치는가 — 한 줄이다

`StepSqlStatementReader.ReadAnchor` 의 마지막 줄.

```csharp
return matchCount == 1 ? ordinal : null;   →   return distinct.Count == 1 ? ordinal : null;
```

**유일성을 일치로 바꾼다.** 이 코퍼스는 한 문장 앞에 주석을 **둘** 둔다 —
기계 라벨 `-- SQL_INSERT1 (INSERT 1, 오류코드 -2)` 와 U-앵커 `/* INSERT1: … */`.
**둘은 같은 서수를 말하는데 유일성 규칙이 그것을 모호성으로 버린다.**

**패턴(`AnchorPattern`)은 건드리지 않는다.** §9 가 「완화는 손해」라고 판정한 것은 옳았고,
고칠 자리가 패턴이 아니라 유일성이었다.

## 2. 발화 단위 — **앵커를 얻는 문장 수. 코퍼스 전체 +6(Job 3).**

| | Batch1 | Batch4 | Batch5 | 합계 |
| :--- | ---: | ---: | ---: | ---: |
| 오늘 | 87 | 78 | 89 | **254** |
| 이 처방 | 90 | 78 | 92 | **260** |

**잃는 문장은 0 이다**(문장 단위 차분으로 확인). 새 앵커 여섯을 전건 열었고 전부 옳다 —
예: `Batch1/S12` 는 `-- … (DELETE 1, 원본 라인 44~50)` 과 `/* DELETE 1: … */` 가
**같은 서수·같은 종류**를 말한다.

## 5. 되돌림 조건

- **R1**: 앵커가 **260 이 아니면** 되돌린다(잃는 문장이 하나라도 있으면 포함).
- **R2**: 스윕에서 **검사 A~E 나 미분류가 하나라도 변하면** 되돌린다.
  기준선 `sweeps/2026-09-08-step-sweep-b.md` — **A 0 · B 2 · C 1 · D 0 · E 0 · 미분류 27**.
  ①이 들어와 있으므로 **B·C 도 불변이어야 한다** — 그것이 ①의 효력이 실물에서 확인되는 자리다.
- **R3**: U-앵커와 코드 앵커의 **충돌이 하나라도 생기면** 되돌린다(오늘 0).
- **R4**: 되돌렸을 때 사라지는 앵커가 **정확히 그 6** 이 아니면 되돌린다.

## 6. 안 하는 것

- **`AnchorPattern` 완화(`\s+` → `\s*`)는 안 한다.** 그것은 ③(T22)의 몫이고, 이 처방과
  함께면 Batch1 이 92 인데 **그때 켜지는 검사 발화를 아직 안 쟀다.**
- **캐시 인상 없음** — 프롬프트 계약이 안 바뀐다(리더만 고친다).
