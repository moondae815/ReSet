# GPT 판 여섯(B11~B16) 결함 교차 분류 (사전 선언)

**작성 시점**: 2026-09-14, **측정 전**. **코드**: main `2f6483eb`. **API 호출 0**(읽기·스크립트만).

## 0. 왜 하는가

오늘은 「GPT 한 판 → 새 결함 하나 → 수정 → 다시 한 판」을 반복했다(B14 · B15 · B16, 약 $19 · 1 시간 45 분). 판마다 목차부터 16 · 19 · 21 단계로 달라
새 결함은 판을 돌리는 한 계속 나오고, 한 판 표본으로 고치고 한 판 표본으로 확인하는 동안 **무엇이 가장 중요한지**는 드러나지 않는다.
이미 있는 여섯 판을 가로질러 결함을 **가족으로 묶어 빈도 · 심각도 · 탐지자 · 현재 상태**로 세운다. 이 표가 (1) 다음에 무엇을 고칠지와
(2) 기본 설정(계획 시도 1~2 회 · GPT Consolidator)을 지금 정할 수 있는지를 정한다.

## 2. 재료(출처) — 다섯

1. **판 안 단계 하한 재생성 사유** — 실행 로그 「하한 검사를 통과하지 못해 다시 생성」 줄, 사유를 ` / ` 로 쪼개 하나씩.
2. **판 안 통합 L1** — 로그 「통합 계획서 기계적 검증 완료」(여섯 판 전부 채택 시도에서 오류 0 — 재료로는 빈다).
3. **Critic 지적** — `raw/attempts/run-001/reviews/attempt-*.json` 의 `DefectiveSteps` · `SkeletonDefective` · `FeedbackComment`.
4. **배송본 배너** — `docs/BatchMigrationPlan.md` 머리의 검증 불가 · 하한 미달 · 생성 실패 항목.
5. **사람 판독** — 오늘까지의 판독 문서(`2026-09-13-*` · `2026-09-14-*` 사전 선언의 실행 결과 절)에 적힌 **배송된** 결함.
6. 보조: 현재 main 의 스윕(`sweeps/2026-09-14-step-sweep-named-block.md`) — 배송 단계 파일에 지금 검사를 다시 댄 값.

## 3. 분류 축

결함 하나(판 · 자리 · 사유)를 아래로 적고, 같은 **메커니즘**끼리 가족으로 묶는다(자리·단계 코드로 묶지 않는다 — 판마다 번호가 다르다).

| 축 | 값 |
| :-- | :-- |
| 층 | 목차 · 골격(공통 규약·흐름) · 단계 본문 · 검증 SQL 세트 · 파이프라인(배너·표시) |
| 결과 | 판 안에서 잡혀 닫힘 · 배송(배너로 표시) · 배송(조용) |
| 탐지자 | L1 단계 · L1 통합 · Critic · 사람 판독 · 없음 |
| 심각도 | **S1** 실행하면 틀린 데이터(행 집합·금액) · **S2** 실행 불가·배치 실패·재시작 불능(권한·게이트·정의 없음) · **S3** 구현자 혼란·비용(중복·모순 산문·재생성 낭비) · **S4** 표시만 |
| 지금 | 닫힘(커밋) · 열림 · 검사 오탐이었음 |

## 4. 판정 규칙

- 「판 안에서 잡혀 닫힘」은 **판 비용**으로만 센다(재생성 횟수) — 배송 결함 수에 넣지 않는다.
- 검사 오탐으로 판명된 사유(예: 이름 블록 · 공통 규약, T25 위치 INSERT)는 결함 가족이 아니라 「검사 오탐」 가족으로 따로 둔다.
- 같은 판 한 자리에서 난 같은 사유는 시도가 여럿이어도 1.
- 사람 판독 출처는 문서 파일·절을 칸에 적는다. 문서가 「배송」이라 적지 않은 것은 배송으로 세지 않는다.

## 5. 이 분류가 못 보는 것 (맹점 — 먼저 적는다)

**탐지자 「없음」 가족은 원리상 이 표에 안 나온다.** 여기 실리는 것은 L1 · Critic · 사람 판독 중 누군가 본 것뿐이고, 사람 판독은 판마다 그날의 물음(RunId 게이트 · 가드 · 통제 합계)만 봤다.
그래서 이 표의 빈도는 **탐지 편향**을 안는다 — 검사가 있는 가족은 많이, 없는 가족은 0 으로 보인다. 결론 문장에 이 한계를 붙인다.
맹점을 줄이려면 단계 단위 축 B 감사(원본 DDL · 명세서 ↔ 단계 섹션)가 필요하고 그것은 API 호출이 드는 별도 작업이다 — §결과 뒤에 비용과 함께 선택지로만 적는다.
