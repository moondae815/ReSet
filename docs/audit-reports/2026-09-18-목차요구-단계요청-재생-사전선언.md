**삽입 자리는 사용자 메시지 꼬리**(제품의 `volatileUserSuffix` 에 해당하는 구간, `Now write the section for step …` 바로 앞)다. 공유 접두사에 넣으면 팔마다 접두사가 갈려 캐시가 죽고 실험비가 세 배가 된다. **제품에서의 자리는 이 결과를 보고 따로 정한다** — 전 단계 불릿을 공유 접두사에 한 번 싣는 편이 캐시에 유리할 수 있고, 그것은 이 실험이 재는 것이 아니다.

**블록 머리글과 A2 문구는 제품에 없는 합성 문장이다.** 결과가 좋아도 이 문구를 그대로 제품에 넣는다는 뜻이 아니다.

### 2-3. 회차와 비용

팔 3 × 자리 3 × **3 회 = 27 호출.** 단계 섹션 요청은 입력 **203,617 토큰**(로그 「토큰 사용량」 줄 실측). gpt-5.6-sol 실청구 $2/$10 → 첫 호출 ≈ $0.45, 같은 접두사 캐시 적중 ≈ $0.15 → **≈ $5.**

> **「재생 실험이 판보다 수십 배 싸다」가 이 자리에서는 성립하지 않는다.** 8 자리 전량(팔 3 × 3 회 = 72 호출)이면 ≈ $13 으로 1 회 판($6.43)보다 비싸다. 그래서 자리를 셋으로 좁혔다 — **도달 8 자리 전량을 잰다고 쓰지 않는다.** 사람 결정(2026-09-18).

## 3. 판정 오라클 — 「무엇이 대응인가」를 실험 전에 못박는다

기계 리터럴로는 못 가린다(§1-1). 그래서 자리마다 판정 문장을 **미리** 적는다. 이 표 밖의 이유로 대응을 인정하지 않는다.

| 자리 | **대응**으로 센다 | **축소 사유**로 센다 | 대응도 사유도 아님 |
| :-- | :-- | :-- | :-- |
| **S03** `:283` | 재시작 판정 문장 또는 SQL 술어에 **배포·앱·어셈블리 버전**의 원본 실행 대 현재 실행 비교가 있다 | 「버전 비교는 하지 않는다」 + 이유(예: 제어 표에 버전 칸이 없다) | 업무일자만 비교 · 버전 낱말만 스쳐 지나감 |
| **S12** `:362` | 제어 합계 SQL 에 **`GROUP BY` 가 있고** 그 그룹 키가 제어 표에 저장된다 | 「정본 DDL 에 그룹 차원 칸이 없어 전 범위 스칼라로 축소한다」류의 명시 | 「그룹별」이라 적고 SQL 은 스칼라 · `GROUP BY` 가 저장 아닌 임시 집계에만 |
| **S19** `:427` | 일곱 항목(건수·거래 금액·PG 수수료·고객 수수료·**VAT**·**입출금 금액**·**취소 부호**)에 각각 대응하는 저장 항목 이름이 있다 | 없는 항목마다 이유가 적혀 있다 | 넷만 저장하고 침묵 · 이름만 나열하고 저장 SQL 에 없음 |

**판정 절차**: 응답 본문을 단계 절로 보고 위 표로 판정한다. 판정은 응답별로 한 줄씩 근거(줄 번호 + 인용)와 함께 기록한다. 응답이 섹션이 아니면(빈 응답·JSON 오류) **판정 불가**로 세고 분모에서 빼되 수를 적는다.

**부작용도 같이 센다** — 이것을 안 세면 처방이 새 가족을 만들고도 통과한다.

| 부작용 | 세는 법 |
| :-- | :-- |
| (러) 확대 — 없던 원본 사실을 제거·보존했다고 적는다 | 신설 단계에서 「원본의 … 제거했다」류 문장 수. 세 자리 전부 레거시 기원이 없다(S03·S12·S19) |
| **두 권위** — 목차를 따라 정본 DDL·명세서를 어긴다 | 제어 표 컬럼(`AttemptNo` 등 번들 정본 DDL 에 없는 이름) 등장 수 · 명세서에 없는 컬럼 등장 수 |
| 길이 폭주 | 응답 문자 수(A0 대비) |

## 6. 이 결함이 지금 무엇을 우연히 덮고 있나

**목차 요구가 단계 요청에 안 실리는 덕에 단계 본문이 목차의 틀린 요구를 안 베꼈다.** 판독 §5-4 가 기준값끼리 어긋난 자리 셋을 적었다 — 등록·잠금 원자성(목차 대 계약) · 잠금 충돌 게시 경로(아키텍처 대 계약) · 제어 표 스키마(목차는 `AttemptNo`·`BatchRunLock.BusinessYmd`, 번들 정본 DDL 에는 `AttemptNo` 가 없고 열 이름이 `BatchYmd`). **B21 은 정본 DDL 을 따랐고 그것이 옳았다.**

## 7. 이 선언이 보증하지 않는 것

- **B21 외 코퍼스의 (나) 건수를 못 쟀다.** §1-1 의 79·23 은 다른 것을 재는 수다. 1418 불릿이 같은 사각지대라는 것은 경로의 성질(§1-2)에서 나온 것이고, 건수가 아니다. 확정하려면 다른 Job 하나를 표본 감사해야 한다 — 이번 범위 밖.
- **(나-2) 4 자리는 이 처방으로 안 닫힌다.** 재료가 이미 실려 있었다.
- **8 자리 중 셋만 실험한다.** 남은 다섯(S01·S04·S13·S19 `:426`·S20)은 처방을 넣은 뒤 실물 판에서 잰다. 특히 7 번(S19 `:426`)은 「적혀 있는데 성립하지 않는」 자리라 재료 처방으로 안 닫힐 수 있다.
- **축 A 는 여전히 미검증이다.** 다만 가족 (나)는 목차 대 산출물이라 「명세서가 옳다」는 전제에 걸리지 않는다 — 이 가족을 먼저 잡는 근거다.
- **L1 검사를 만들지 않는다.** 앞 층 ①에서 기각했다. 처방이 프롬프트 층이므로 뒤 층 셋(발화·오탐·되돌림) 대신 **A0 대조군이 되돌림 자리**이고, 오탐 자리는 §3 의 부작용 표가 맡는다.

# 부록 A — A3·A4 팔 (2026-09-18, 1 차 결과 뒤 추가 선언 · 실행 전)
