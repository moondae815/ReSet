# 실행 순서를 문서 순서로 짐작하지 않는다 — 목차가 정본이다 (사전 선언)

**작성 시점**: 2026-09-17, **구현 전**. **코드**: main `f05eb726` + 이 문서 커밋.

## 0. 잰 것

B19 판독(`2026-09-17-GPT-2회판-Batch19-사전선언.md` §발견 1)의 자리다. 첫 L1 회차 오류 11 중 **아홉이 RunId 게이트 오탐**이었다 — 「`S13` 이 RunId 를 발급하는 `S02` 보다 먼저 실행된다」. 원인은 두 검사(`CheckGateRequiresStepsBeforeRunId` · `CheckPreRunIdRunIdWrites`)가 **문서 순서를 실행 순서의 대리**로 쓰는 것이고, B19 배송본의 첫 `### Sxx` 헤딩이 Mermaid 흐름도 안의 `### S13～S16 요약 복합 트랜잭션` 이었다. 대가: 수리 회차 하나 소진 · **모델이 멀쩡한 게이트에서 S13 을 지웠다** · 판이 L1 미통과로 배송돼 L2 에 도달하지 못했다.

### 마크다운만으로 순서를 고칠 수 있는가 — 두 후보를 코퍼스 15 편으로 쟀다

세는 자: 배송본의 `### Sxx` 헤딩을 위에서부터 읽어 **처음 등장한 순서**가 목차 JSON 의 단계 순서와 같은가.

| Job | 현행(문서 순서) | ① 단계 상세 H2 안의 헤딩만 | ② 범위 헤딩(`S13～S16`) 제외 |
| :-- | :-- | :-- | :-- |
| 13 편 | 일치 | 일치 | 일치 |
| **B14** | **불일치** — 첫 헤딩이 아키텍처 절의 `### S11 통합 범위` | 일치 | **불일치**(범위 헤딩이 아니다) |
| **B19** | **불일치** — 첫 헤딩이 흐름도 절의 `### S13～S16 …` | 일치 | 일치 |
| **B7** | 일치 | **불일치** — 모델이 단계 영역 안에 H2(`## 재시작/복구 전략`)를 끼워 넣어 진짜 S13~S17 이 그 밑에 있다 | 일치 |

**어느 규칙도 열다섯을 다 맞추지 못한다.** ①은 진짜 단계를 버리고(B7), ②는 범위가 아닌 헤딩을 못 거른다(B14). 문서 모양으로 순서를 짐작하는 한 모델이 헤딩을 어디에 두느냐에 따라 계속 깨진다 — **순서의 정본은 목차**다(파이프라인이 이미 들고 있다).

### 호출부가 목차를 넘길 수 있는가

`ValidateConsolidated(string markdown)` 는 목차를 받지 않는다. 호출부는 둘이고 둘 다 단계 목록이 손에 있다 — `VerificationPipelineOrchestrator` 2319(`currentSteps`) · 3422(`stepsForRegeneration`). 둘 다 null 일 수 있다(단일 호출 폴백 경로). `_validator` 는 구체 형식(`MechanicalValidator`)이라 **선택 매개변수를 더해도 시험 52 자리는 그대로 컴파일된다.**

## 1. 설계

- `ValidateConsolidated(string markdown, IReadOnlyList<BatchStepPlan>? steps = null)`.
- 두 순서 의존 검사에 `steps` 를 넘긴다. **`steps` 가 있으면 실행 순서는 목차 순서다**: 발급 단계는 「목차 순서로 처음, 자기 절 본문이 `batch.BatchRun` 에 INSERT 하는 단계」이고, 「발급 전」은 목차에서 그보다 앞선 단계다. 절 **본문**은 지금처럼 `SplitStepSections` 로 모은다(같은 코드의 절은 합친다 — 흐름도의 `### S13～S16` 아래 mermaid 펜스는 S13 본문에 붙지만 SQL 이 없어 판정에 영향이 없다).
- **`steps` 가 null 이면 종전 경로 그대로**(문서 순서) — 목차를 모르는 호출은 행동이 바뀌지 않는다.
- 오케스트레이터 두 호출부가 단계 목록을 넘긴다.

**범위 밖**: `SplitStepSections` 의 절 경계 규칙 자체(범위 헤딩을 절로 안 치기) — 측정상 순서 문제는 목차로 닫히고 경계 규칙만으로는 닫히지 않는다. 경계가 다른 검사에 주는 영향은 이 회차에서 건드리지 않는다.
