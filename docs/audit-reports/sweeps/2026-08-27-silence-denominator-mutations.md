# 침묵 분모의 변이 검증 (2026-08-27)

계기가 **0 을 인쇄하고 통과했다고 말하는 또 하나의 검사**가 되지 않게, 판정 단위마다 변이를 넣고
계수가 움직이는지 봤다. 조건이 아니라 판정 단위다.

**제품 코드는 전부 되돌렸다.** 변이는 `/tmp` 의 전용 워크트리에서만 돌렸다 — 공유 체크아웃에서
제품 코드를 일시 변이시키면 다른 세션이 그 변이를 커밋할 수 있다.

## 실행 조건

- 커밋: `3a59030` (변이 워크트리도 같은 커밋)
- 측정 쌍: 326 (Job 18개) · 캐시 `FormatVersion` 집합 `{16}` · 항목 31개
- 워크트리 기준선이 메인 체크아웃 기준선과 **열 계수 전부 일치**함을 먼저 확인했다

## 변이 셋의 결과 — **셋 다 죽었다**

| 변이 | 움직여야 하는 계수 | 기준선 → 변이 | 판정 |
| :--- | :--- | :--- | :--- |
| `ReadsOnlyStaging` 에서 `!statement.ReadsOwnTarget` 제거 | 면제 취소 수 | **35 → 0** · 면제 수 **105 → 140** | 죽음 |
| `specTargetsForStep` 을 빈 집합으로 | 스테이징 원천 총수 · 면제 수 | **141 → 143** · **105 → 107** | 죽음 |
| `codeMapForStep` 을 빈 사전으로 | 해결 / 미해결 | **856 → 18** · **233 → 1155** · 버림 **84 → 0** | 죽음 |

**안 죽은 변이: 없음.**

### 변이 1 이 가장 값진 결과다 — 산술이 정확하다

「면제 취소」가 35 → 0 으로 가는 동시에 「스테이징만 읽어 검사 C 가 면제한 문장 수」가
105 → 140 으로 **정확히 35 만큼** 늘었다. 그 35 개 문장이 「취소됨」에서 「면제됨」으로 그대로
옮겨 간 것이다. 계수가 주장하는 바로 그 경로를 재고 있다는 뜻이며, 우연히 함께 움직이는 수가
아니다.

그 35 는 2026-08-27 `staging-lineage` 최종 리뷰가 Critical 1 로 보고한 **35 좌표**와 같은 수다.
`ReadsOwnTarget` 가드를 끄면 그 35 좌표에서 검사 C 가 다시 꺼진다 — 이 계수는 **그 방어가 살아
있는지**를 매 스윕마다 세는 자리다.

### 변이 2 는 죽었으나 폭이 작다 — 그리고 그 작음이 문서와 맞는다

+2 뿐이다. 이는 설계서 `2026-08-27-staging-lineage-design.md` §2-1 이 **스스로 정정한 내용**과
일치한다: `specTargets` 제외가 실제로 막는 것은 재게시 관용구가 아니라 **스키마가 다른 동명
테이블의 베이스 이름 충돌**이고(실측 좌표 `POQSettleProc8/S08`), 그런 자리는 코퍼스에 몇 건뿐이다.
변이가 죽었고, 그 폭이 문서화된 실측을 뒷받침한다.

### 변이 3 은 예측이 틀렸고, 틀린 자리가 사실을 하나 냈다

계획서는 「해결 수가 **0** 이 되어야 한다」고 적었다. 실제로는 **18** 이다.

`ResolveOrdinal` 은 코드 앵커뿐 아니라 **U-앵커**(`statement.Anchor`)로도 서수를 낸다. 코드 사전을
비워도 U-앵커만으로 서는 문장이 남는다. 즉 **이 코퍼스에는 U-앵커만으로 해결되는 문장이 18 개**
있다. 잰 적 없던 값이고, 계획서의 예측이 틀렸기에 드러났다.

## 변이가 공짜로 내준 구조적 교차검증

세 계수 사이에 불변식이 성립해야 한다:

```
앵커 해결 + 모호성으로 버림 + 앵커 미해결 = 앵커를 보유한 문장 수
```

| | 계산 | 합 |
| :--- | :--- | ---: |
| 기준선 | 856 + 84 + 233 | **1173** |
| 변이 3 | 18 + 0 + 1155 | **1173** |

**두 상태에서 같다.** 세 계수가 같은 분모를 공유하며 서로 어긋나지 않는다는 뜻이다. 이 확인은
변이를 돌리지 않았으면 나오지 않았다.

## 잰 것과 안 잰 것

- **잰 것**: 열 계수의 기준선, 변이 셋 각각의 전체 표, 위 불변식
- **안 잰 것**: 나머지 일곱 계수를 각각 겨눈 변이(이번에는 셋만 넣었다) · 승격 후의 값
  (태스크 11 이 잰다) · 계수를 좌표에 귀속시키는 것(설계상 범위 밖)
