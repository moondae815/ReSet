# 축 B 잔여 결함 22건의 처리 방침 분류

축 B 재감사(`2026-09-05-POQSettleBatch1-축B-재감사.md`)가 남긴 것 중, **검사가 이미 잡게 된 것과
🔴 하나를 뺀 22건**을 「어떻게 닫을 것인가」로 가른다.

**대상**: 잔존 13(§3의 `R`·`R′`에서 T02 제외) + 신규 9(§4의 N4~N12).
**뺀 것 넷**: T02(🔴 — 별도 과제로 크기를 재는 중) · N1·N3(검사 B 접힘을 좁혀 잡음 `83bdf03f`) ·
N2(중복 투영 검사로 잡음 `1f7ea018`).

**이 문서는 분류만 한다. 어느 것도 구현하지 않는다.**

## 어휘 — 결과를 보기 전에 정했다

| 기호 | 뜻 |
| :--- | :--- |
| **K¹** | **기존 검사의 판별자를 넓혀** 닫는다 — 재료는 이미 있고 검사가 그 칸을 안 볼 뿐이다 |
| **K²** | **새 검사**로 닫는다 |
| **P** | **프롬프트·공통 규약**으로 닫는다 — 기계로 판정할 수는 없으나 지시할 수는 있다 |
| **N** | **기록만 한다** — 손댈 수단이 없거나, 상류 계약이 그렇게 정한 것이다 |
| **U** | **분류 불가** — 판정에 필요한 사실이나 결정이 없다. **무엇을 재야 하는지를 함께 적는다** |

`K`를 둘로 가른 것은 동료 세션 `reset-b1`의 지적이다 — **「재료는 있는데 판별자가 느슨한 것」과
「재료가 아예 없는 것」은 처방이 다르다.** 한 건도 분류하기 전에 넣었다.

**미리 못박은 것 둘**
- **「재생성하면 낫겠지」는 분류가 아니다.** 궤적 46 → 42 → 40이 이미 반증했다.
  재생성으로 닫히는 것은 **그 앞에 검사가 있을 때만** `K`다.
- **`U`를 `K`로 올려 적지 않는다.** 같은 날 접힘에서 「가를 수 있을 것 같다」로 갔다가 한 번 되돌렸다.

## 1. K¹ — 재료가 이미 있다. 검사가 그 칸을 안 볼 뿐이다

| ID | 자리 | 오라클 | 요지 |
| :--- | :--- | :--- | :--- |
| T22 | `STAT_PGCOLLECT` | **DML 범위 표의 `ORDER BY` 칸** | 그 칸이 `INYMD, CLIENTID, PGNAME, MALLID`를 확정하는데 단계에 `ORDER BY`가 0건이다. 검사 B는 술어·조인 키만 보고 이 칸을 안 본다 — **가장 싼 한 건** |
| T21 | `STAT_PGCOLLECT` | INSERT 매핑 표의 「원천 표현식」 칸 | `LOWER(CLIENTID)` 등이 외부 `SELECT`·`GROUP BY`에 없다. 2026-09-05 SET 산식 검사와 **같은 재료**이고 관할만 INSERT 매핑으로 넓히면 된다 |
| T29 | `INS_EXTRA4PLCARD` | 오류 코드 표(기계 확정) | 표는 `UPDATE 2 │ -2` 한 행뿐인데 단계가 INSERT 1·UPDATE 1에도 `-2`를 배정한다. 「어느 문장에 어느 코드」를 코드 앵커와 대조하면 잡힌다 |

## 4. ★ U — 분류 불가 다섯. 그러나 **결정 셋**으로 접힌다

**이것이 이 문서의 요점이다.** 여섯이 흩어진 미지가 아니라 세 덩어리다.

### 결정 (가) — 단계가 금액 **타입**을 못박아야 하는가 · 2건 (T02와 한 뿌리)

| ID | 요지 |
| :--- | :--- |
| N4 | 대사 두 문장에서 `ISNULL(…,0)`·`CAST(… AS MONEY)` 방어가 사라져 `NULL` 취급이 이행자에게 위임됐다 |
| (T02) | *(이 문서 밖 — 남은 🔴)* 금액 변수의 타입이 단계 어디에도 없다 |

**재야 할 것**: 검사 D는 **선언의 유무**를 보지 **타입의 옳음**을 안 본다. 새 검사인지, 단계 형태를
T-SQL로 되돌리는 결정인지가 먼저다. **T02의 크기 재기가 N4도 함께 판정해야 한다.**

### 결정 (나) — 단계가 **세션 옵션·트랜잭션 진입 정리**를 이행해야 하는가 · 3건

| ID | 요지 |
| :--- | :--- |
| T20 | `NOCOUNT` 0건 · `TRANCOUNT` 0건. 검사 없이 바로 `beginTransaction()` |
| T33 | `SET NOCOUNT ON`이 후 Job 트리에서 이행 선언으로 0건 |
| T31 | `@po_intRetVal` 기본값 `1000`이 없다 — **Job 전역 규칙 6-1(「NULL로 시작한다」)이 명세서와 정면으로 어긋난다** |

**재야 할 것**: 후 단계가 「격리 설정은 이 단계가 지시하지 않는다」로 **명시적으로 손을 뗐다.**
그것이 의도라면 셋 다 `N`이고, 의도가 아니라면 `K¹`이다. **T31은 특히 `check-oracle-provenance`가
말한 「두 오라클이 반대를 말한다」 자리다** — 규칙 6-1과 명세서 중 어느 것이 기준인지 정하기 전에
검사를 넓히면 오탐만 는다.

### 결정 (다) — 검사에 **원본 DDL**을 들일 것인가 · 1건

| ID | 요지 |
| :--- | :--- |
| N5 | 갱신 11의 `TClientCMRate` 결합이 `B.*` → `A.*`로 옮겨갔다. **명세서 조인 키 칸은 별칭을 안 적어** 이 자리를 기계로 못 가린다 |

**재야 할 것**: 2026-09-05 스파이크가 이미 쟀다 — **조인 짝은 명세서에 없다.** 원본 DDL에는 있고,
그것을 검사에 들이는 두 길(명세서에 실어 전건 재생성 / 검사 때 재파생해 둘째 오라클)이 미결이다.
그 결정이 나면 N5는 `K¹`이 된다.

## 5. N — 기록만 한다

| ID | 왜 |
| :--- | :--- |
| G03 | `WITH(NOLOCK)` 42곳 소실은 **전역 정책이 명시적으로 정한 것**이다. 감사도 ⚪로 뒀다. 격리 선언이 단계 밖으로 나간 것은 (나)에서 함께 본다 |
| N9 | `WITH (UPDLOCK, HOLDLOCK)` 소실은 **원본에 없던 것을 전 단계가 더했던** 안전장치다. 원본 대비 결함이 아니라 전 대비 후퇴다 |
| N11 | 날짜 형식 검증(`B100`) 소실은 **상류 계약의 변경**이다 — 후 `[Approved Step List]`의 `ErrorCodes`가 `-9010` 하나로 줄었다. 이행 결함이 아니다 |
| **N8** | **전제가 거짓으로 확인됐다 — 결함이 아니다.** 기정산 가드가 `IF EXISTS` → 스칼라 `IS NOT NULL`로 바뀐 것은 **`TSettleMst.PLTID`가 NULL 허용일 때만** 위험한데, 오프라인 스냅샷(`output/offline_snapshot.json`)의 컬럼 메타데이터가 그 컬럼을 **`varchar(40)` · `IsNullable=False`**로 확정한다. `ORDER BY` 없는 `SELECT TOP 1 PLTID`가 NULL을 집을 수 없으므로 `IS NOT NULL`은 `EXISTS`와 동치다. 재감사 단위가 「전제가 깨지면 ⚪」이라 적은 그대로다. **로컬 DB가 빈 스키마라 못 잰다고 여겼는데, 스냅샷에 있었다**([[db-access-constraints]]가 말한 「리터럴로 답나는 질문」의 한 자리다) |

## 6. 이 분류가 보증하지 않는 것

- **분류이지 판정이 아니다.** 각 건이 진짜 결함인지는 재감사가 이미 판정했고, 여기서 다시 열지 않았다.
- **K로 분류한 8건의 검사를 설계하지 않았다.** 오라클이 있다는 것까지가 이 문서의 주장이고,
  그 오라클이 **충분한지**는 설계에서 다시 봐야 한다(T25는 절반이 산문이라 이미 약하다고 적었다).
- **P로 분류한 5건의 문구를 쓰지 않았다.** 어느 문서(프롬프트·공통 규약·규칙)를 고치는지도 안 정했다.
- **남은 U 다섯은 사람 결정이 앞에 있어 재도 안 풀린다.** 여섯째(N8)는 스냅샷을 열어 닫았다 —
  **다른 U에도 그런 것이 있는지는 각 결정 문단의 「재야 할 것」이 스키마 사실인지로 갈린다.**
  (가)·(나)·(다)는 전부 정책·설계 결정이라 그렇지 않다.
- **N 넷을 원장에서 닫을지 열어 둘지 정하지 않았다.** 결과를 보고 정하기로 했고, 셋은
  「상류가 그렇게 정했다」 부류이고 N8은 아예 결함이 아니라 **닫는 쪽이 자연스러우나 사람 결정이다.**
