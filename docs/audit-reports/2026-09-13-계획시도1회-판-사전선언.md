# 계획 시도 1회 판 — `POQSettleBatch10` (사전 선언)

**작성 시점**: 2026-09-13, **실행 전**. 합격선과 예측을 결과보다 먼저 못박는다.
**코드**: main `a515f830`(검사 B 조인 키 칸 되읽기 수정 포함) + 이 문서·스크립트 커밋.

## 0. 물음

한 판이 4 시간·(GPT 환산) $86~107 이 드는 원인을 2026-09-13 에 쟀다.

- 계획 시도(골격 → 단계 본문 → Critic 리뷰)를 **7 번** 돌았고(5차의 L1 수리 2 회 포함) **시간·호출의 약 80% 가 2 차 이후**였다.
- 점수는 오르지 않았다 — Batch9 `76 → 74 → 74 → 78`(4차 채택), Batch8 `? → 82 → ? → 74 → 78`(2차 채택). **Critic 점수의 판 안 흔들림이 74~82 다.**
- 단계 하한 재생성 114 회 중 90 회가 검사 B 오탐이었고 그것은 `a515f830` 에서 고쳤다.

**이 판이 재는 것은 구조 변경 하나다 — 계획 시도를 1 회로 줄이면 시간·호출이 얼마나 줄고 산출물이 쓸 만한가.**
모델은 바꾸지 않는다(변인을 겹치지 않는다).

## 1. 실행 조건 — 이전 판과 같게 못박는다

| 항목 | 값 | Batch8·9 와 |
| :--- | :--- | :--- |
| 경로 | `scripts/run-plan-only-job.sh POQSettleBatch10` | 같음 |
| Actor · Consolidator | `claude-cli` / `claude-sonnet-5` (환경변수) | 같음 |
| Critic | 로컬 설정 `OpenRouter` / `z-ai/glm-5.3` (못박지 않음 — 실행 로그로 사후 확인) | 같음 |

**처치가 둘인 것을 숨기지 않는다.** 시간·호출 감소를 둘로 나눠 귀속하려면 로그의 하한 재생성 사유를 센다

## 5. 알려진 위험

- **L1 이 3 번(첫 판 + 수리 2) 모두 떨어지면** 채점된 후보가 없을 수 있다. Batch9 는 5차에서 같은 린트(「위와 동일」)로
  L1 수리를 소진하고 이전 채점 후보로 되돌렸다. 1 회 판에는 되돌릴 후보가 없다 — 그때 무엇이 채택되는지를 적는다.
- claude-cli 구독 쿼터가 중간에 소진되면 판이 끊긴다(저널로 이어 달리기는 같은 Job 이름으로 가능).
- 산출물은 새 디렉터리 하나라 되돌리기는 이동 한 번이다. 기존 Job·명세서는 이 경로가 쓰지 않는다.
