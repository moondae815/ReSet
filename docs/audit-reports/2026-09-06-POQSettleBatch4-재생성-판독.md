### T02 는 그대로다 — 자리만 옮겼다(S09 → S11)

```
원본  PROC_ETC:116  SELECT @v_intPostChkAmt1 = ISNULL(SUM(CAST(CLTotal      AS MONEY)),0)
      PROC_ETC:130  SELECT @v_intPostChkAmt2 = ISNULL(SUM(CAST(CLSettleAmt AS MONEY)),0)

Batch4 S11:232      SELECT SUM(A.CLTotal)        ← CAST 없음 · ISNULL 없음
       S11:244      SELECT SUM(CLSettleAmt)      ← 없음
```

**새 모델·새 회차에서 같은 자리가 다시 났다.** 그리고 `WHERE ISNULL(B.TaxFGBill,2) = 1` 이
그대로 살아 있어, 「술어의 `ISNULL` 을 투영의 방어로 오인하는 함정」의 모양도 재현됐다
(T02 검사 설계 §4 의 그 자리다).

### 회귀 A·B 는 닫혔는데 **검사가 민 증거는 없다**

`ON B.YMD = A.OrgYMD` · `C.MALLID = A.MALLID` 로 원본대로 나왔고 계획서에 근거 주석까지 붙었다
(「누락 시 적재 행 집합이 원본과 달라짐」). **그러나 생성 로그에 조인 키 관련 L1 발화가 없다.**
그러므로 **「접기 좁힘 검사가 밀었다」로 읽으면 안 된다** — 모델이 명세서를 더 충실히 따른 것과
구별되지 않는다. 이 회차가 답하지 못하는 자리다.

### N12 는 술어가 대칭이지만 **Critic 이 더 깊은 것을 지목했다**

S11·S15 모두 캡처 술어 = 복구 `DELETE` 술어다. 그런데 Critic 이 S11 에서
**캡처 범위가 갱신 범위보다 좁다**고 지적했다 — 갱신 대상은 `ClientID+OutYMD+OutState+IssueType`
로 조회되는데 캡처는 `YMD=@p_strYMD AND OutState=2 AND IssueType=15` 라, `YMD≠batchYmd` 인
기존 행이 갱신되면 복구 시 유실된다.

**이것은 내가 N12 로 설계했던 「캡처 술어 = 복구 술어」 대조로는 못 잡는다.**
술어는 대칭인데 **범위 자체가 부족**하기 때문이다. N12 를 안 만들기로 한 판단과 별개로,
그 설계의 한계를 실물이 보여줬다.

## 4. L1 은 실제로 밀었다 — 두 자리에서

**이 회차가 답할 진짜 질문(사전 선언 §3)에 대한 답이다.**

```
시도 1/6  NOLOCK 잠금 힌트 42건  → 「L1 위반을 S07 자리로 좁혀 그 자리만 다시 만듭니다」
시도 4/6  규칙 3-1 위반(`end try` 1건) → 자가 수정 보완 5회째
```

**좁힌 재생성이 작동했다** — 전량 재생성이 아니라 위반 자리만 다시 만들었다.
다만 **밀린 것은 계획서 층의 검사(NOLOCK·규칙 3-1)뿐**이고,
오늘 통합한 단계 층 검사들(접기 좁힘·중복 투영·명부·N5 조인 짝)이 민 흔적은 로그에 없다.

## 6. Critic 이 지목한 결함 넷 — 둘이 치명적

1. **[S03 치명]** `PGCOMM` 에 원본의 `CASE` 분기가 빠졌다(`PGVT` 에는 있다).
   `CLCOMM`·`CLETC`·`PGETC` 의 0방향 절삭 `CAST` 도 누락 — 암시적 반올림으로 금액이 달라진다.
2. **[S13 치명]** 청크 키를 `OUTYMD+CLIENTID+PGNAME` **문자열 결합**으로 두고
   `to = from + 10000` **산술**을 건다. **청크 루프가 동작 불능**이다.
3. **[S15]** 원본에 없는 필터(`OUTSTATE=9 AND USESTATE=0 AND OUTYMD IS NOT NULL`)를 더해
   요약 재적재에서 행이 누락될 수 있다.
4. **[S11]** 위 §3 의 섀도우 캡처 범위 부족.

**2 번은 오늘 `7feb3c54` 로 Few-Shot 을 고친 그 부류다** — 그때 「원인은 닫았으나 배송본은
안 닫혔다」고 적었는데, **새 생성에서도 다시 났다.** 청크 키를 실존 정수 컬럼으로 강제하는
자리가 여전히 비어 있다는 뜻이다.

- **회귀 A·B 를 검사가 닫았는지.** §3 에 적은 대로 구별이 안 된다.
- **중단된 `POQSettleBatch3`(단계 26)의 무엇도.**

## 9. 남는 것

**이 산출물은 배송 가능한 상태가 아니다** — Critic 이 치명 둘을 지목했고 `S08` 이 하한 미달이다.
다음 걸음의 후보는 셋이고 크기가 다르다.

1. **`S08` 만 다시 만든다** — 결함이 한 단계에 몰려 있다. 가장 싸다.
2. **치명 둘(S03·S13)을 사람이 고친다** — Critic 이 자리와 원본 라인까지 지목했다.
3. **T02·청크 키를 계약으로 올린다** — **둘 다 「고쳤는데 다시 났다」**는 공통점이 있다.
   개별 산출물을 고치는 것으로는 다음 회차에 또 난다.
