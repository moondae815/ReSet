# `AnchorPattern` 완화 — 착수 전 사전 선언

**코드를 만지기 전에 적는다.** 작성 2026-09-08. 기준 커밋 `c73a6360`(main).
워크트리 `.worktrees/t22` · 브랜치 `feat/axis-b-pattern-relax` · 코퍼스 심링크 `output/` 하나.

**출처**: `2026-09-05-앵커-도달률-판독.md` §9(「완화는 손해」 판정과 그 미해명) ·
`2026-09-08-U앵커-판독.md` §6. 순서 `① 이전 면제 → ② U-앵커 한 줄 → ③ 이것`의 **③**이다.

## 0. 공통 규율

- **빌드·테스트는 이 격리 워크트리에서만.**
- **게이트는 파일로 받고 `$?` 를 직접 찍는다.**
- **새 발화는 전부 열어 본다. 숫자를 맞추려고 아래 조건을 손보지 않는다.**

## 1. ★ 이 변경은 **한 번 기각된 적이 있다** — 그 판정이 왜 뒤집히는지부터 적는다

§9(2026-09-06)가 완화를 **실측으로 기각**했다: Batch1 앵커 **87 → 84**, 「왜 5 를 잃는지
못 밝혔다. 모르는 채로 넣지 않는다」.

**그 판정은 옳았고, 원인이 패턴이 아니었다.** `2026-09-08-U앵커-실측.md` §1 이 밝혔듯
손실의 기제는 `ReadAnchor` 의 **유일성 규칙**이었다 — 완화하면 기계 라벨과 U-앵커가 **둘 다**
매치해 `matchCount == 2` 가 되고 앵커가 통째로 버려졌다. **②가 그 규칙을 일치로 바꿨으므로
손실의 원인이 이미 없다.**

**그러므로 이 회차는 「기각을 뒤집는 회차」다.** 근거는 새 실측이지 새 의견이 아니다.

## 2. 무엇을 고치는가

```
(?:\bU|\b갱신\s*|\bUPDATE\s+|\bINSERT\s+|\bDELETE\s+)   →   … \bUPDATE\s*|\bINSERT\s*|\bDELETE\s*
```

`\bU` 와 `\b갱신\s*` 은 이미 공백 없이도 받는다 — **셋만 일관성이 없었다.**

## 3. 발화 단위 — **앵커를 얻는 문장 수. 코퍼스 전체 +2(Batch1 만).**

| | Batch1 | Batch4 | Batch5 | 합계 |
| :--- | ---: | ---: | ---: | ---: |
| ①+② (오늘) | 90 | 78 | 92 | **260** |
| +③ | **92** | 78 | 92 | **262** |

**얻는 둘은 `POQSettleBatch1/S15` 의 `DELETE1`·`INSERT1`** 이다(`-- DELETE1: …` 처럼 공백이 없어
현행 패턴이 못 읽던 자리). **잃는 문장 0.**

## 4. 여섯 조건 — 앞 다섯을 착수 전에 실측했다

| # | 조건 | 값 |
| ---: | :--- | :--- |
| 1 | 재료 | 단계 본문의 주석. 리더가 이미 읽는다 |
| 2 | 도달 | `ReadAnchor` 는 모든 단계에서 돈다 |
| 3 | 그 자 | 세 대안의 공백 요구를 나머지 둘과 맞춘다 |
| 4 | 효과 | 앵커 **260 → 262** · 손실 **0** |
| 5 | 오탐 | **검사 발화 변화 0** — 스윕 카운트와 **B·C 발화 목록까지 완전 일치** |
| 6 | 없앴을 때 | 앵커가 262 → 260 으로 돌아와야 한다 |

## 5. 되돌림 조건

- **R1**: 앵커가 **262 가 아니면** 되돌린다(잃는 문장이 하나라도 있으면 포함).
- **R2**: 스윕에서 **검사 A~E 나 미분류가 하나라도 변하면** 되돌린다.
  기준선 `sweeps/2026-09-08-step-sweep-b.md` — **A 0 · B 2 · C 1 · D 0 · E 0 · 미분류 27**.
- **R3**: `AnchorPattern` 이 **종류를 버린다**는 알려진 성질(§9)이 실물에서 물리면 되돌린다 —
  `/* INSERT1: … */` 주석이 `DELETE` 문장 앞에 있으면 그 `DELETE` 가 서수 1 을 받는다.
  **오늘 U-앵커의 `(Kind, 서수)` 쌍이 명세서에 없는 경우가 코퍼스 전체 0 이라 안 물린다** —
  완화 뒤에도 **0 이어야 한다.**
- **R4**: 되돌렸을 때 사라지는 앵커가 **정확히 그 2** 가 아니면 되돌린다.

## 6. 안 하는 것

- **T22 검사는 이 회차에 안 만든다.** 이 완화가 그 재료의 **도달을 0 → 1 로 여는 것**까지가
  ③이고, 검사를 만들지는 **재고 나서 따로 정한다**(§11 이 한 번 만들었다 되돌린 자리다).
- **캐시 인상 없음** — 리더만 고친다.
