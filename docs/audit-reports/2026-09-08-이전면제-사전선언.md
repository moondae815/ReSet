## 0. ★ 이 회차의 최대 위험 — **오늘 관측 효과가 0 이다**

**이것은 발화를 늘리는 검사가 아니라 줄이는 면제다.** 그리고 면제할 대상인 두 발화는
**오늘 존재하지 않는다** — `Batch1/S12/INSERT 1` 은 앵커가 없어 검사 B·C 가 아예 안 돈다
(그 앵커를 살리는 것이 ② U-앵커 한 줄이고, 이 면제가 그 선결이다).

그래서 **평소의 조건 ④(발화한다)가 이 회차에는 성립하지 않는다.** 그대로 두면
「값 0 을 게이트 통과시킨다」는 이 저장소의 실패 모드에 그대로 들어간다.

**대응 셋을 미리 못박는다.**

1. **효력은 ②를 켠 상태에서 잰다.** 던지는 워크트리에서 `ReadAnchor` 의 한 줄을 함께 켜고
   스윕을 돌려 **검사 B·C 발화가 켜지지 않는 것**을 확인한다. 그것이 이 면제의 효력이다.
2. **단위 시험이 면제를 직접 못박는다** — 면제가 죽으면 시험이 빨개져야 한다.
3. **코퍼스 시험이 서명 수를 못박는다**(오늘 문장 2). 코퍼스가 바뀌어 서명이 사라지면
   면제는 조용해지는데, 그것을 「정상」으로 읽지 않기 위해서다.

## 1. 무엇을 면제하는가

원본이 **커서로 집계 그룹을 순회**하고 이행이 그것을 **집합 연산으로 치환**하면,
커서 변수였던 술어는 **옮겨간 것이 아니라 개념이 사라진다.** 기존 `relocated`
(하위 스코프로 옮겨간 컬럼)로는 원리적으로 안 걸린다.

실물(`UP_Util_Settle_Summary_AcqManual`):

```
SELECT 1 · 술어[EDIReqYmd, AcqType, OutState] · GROUP BY[OutYMD, ClientID, PGName]
DELETE 1 · 술어[OutYMD, ClientID, PGName]      ← 커서 변수
INSERT 1 · 술어[OUTYMD, CLIENTID, PGNAME]      ← 커서 변수
```

## 2. 서명 — 셋을 **전부** 요구한다

쓰기 행 `W`(Kind ≠ SELECT)에 대해:

1. `W` 의 최상위 술어 집합이 **비어 있지 않다**.
2. 같은 프로시저에 `SELECT s` 가 있고 그 `GROUP BY` 가 **비어 있지 않으며 `W` 의 술어와 정확히 같다.**
   **그런 `s` 가 둘 이상이면 침묵한다** — 귀속이 모호하다(작성 계약 7).
3. 그 프로시저의 **원본 DDL 에 `DECLARE … CURSOR` 가 있다.**

**③ 은 오늘 발화를 하나도 안 바꾼다**(실측: GROUP BY 일치 2 건이 이미 커서 SP 안이다).
**그래도 넣는다 — 이것은 침묵시키는 변경이고, 침묵시키는 것은 좁은 쪽이 안전한 방향이다.**
커서가 없는 SP 에서 「술어 == 어떤 SELECT 의 GROUP BY」는 관용구가 아니라 우연이다.
**「오늘 값을 하지 않는 변경은 하지 않는다」의 예외이고, 그 이유를 여기 적어 둔다.**

## 3. 무엇을 면제하는가 — 두 검사에서 다르다

| 검사 | 면제 대상 | 근거 |
| :--- | :--- | :--- |
| B | `W` 의 술어 컬럼(= `s` 의 GROUP BY 집합) | 커서 변수다. 집합 치환에서 사라지는 것이 정당 |
| C | `W` 에 더해진 조건 중 **`s` 의 술어 컬럼**인 것 | 원본이 그 필터를 `s` 에서 걸었다 |

**B 는 기존 `relocated` 에 합류시킨다** — 그 집합이 이미 컬럼 단위로 걸러 주고,
「하나는 이전이고 하나는 진짜 소실이면 소실만 발화한다」는 성질을 그대로 물려받는다.

## 4. 발화 단위 — **면제되는 (문장, 컬럼) 쌍. 오늘 문장 2.**

`AcqManual` 의 `DELETE 1`·`INSERT 1` 둘이고, 각각 B 쪽 3 컬럼 · C 쪽 3 컬럼이다.
**오늘 코퍼스에서 실제로 침묵시키는 발화는 0 이다**(§0).

## 6. 되돌림 조건

- **R1**: ②를 켠 상태에서 면제가 **그 둘을 못 막으면** 되돌린다.
- **R2**: 오늘 스윕이 **하나라도 줄면** 되돌린다 — 기준선 `sweeps/2026-09-08-step-sweep-b.md`
  (**A 0 · B 2 · C 1 · D 0 · E 0 · 미분류 27**). 이 면제는 오늘 아무것도 안 지워야 한다.
- **R3**: `SUMMARY_ETC`(`Batch4/S15`)의 검사 C 발화가 **사라지면 되돌린다.** 그것이 이 면제의
  거짓 침묵을 재는 자다.
- **R4**: 면제를 되돌렸을 때 ②-켠 상태의 새 발화가 **정확히 그 둘**이 아니면 되돌린다.

## 7. 안 하는 것

- **②(U-앵커 한 줄)는 이 회차에 안 싣는다.** 순서가 ①→②이고, 이 회차는 ①이다.
  ②는 측정에만 쓰고 되돌린다.
- **산문을 안 읽는다.** 단계가 「커서를 상관 EXISTS 로 치환」이라 적지만 방증일 뿐이다.
- **캐시 인상 없음** — 프롬프트 계약이 안 바뀐다(L1 만 좁힌다).
