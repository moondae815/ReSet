```sql

    SELECT N'LedgerRowCount' AS ControlName, LedgerRowCount AS ControlValue FROM Ledger
    UNION ALL
    SELECT N'TxAmtSum', TxAmtSum FROM Ledger

)
INSERT INTO batch.BatchControlTotal (RunId, StepCode, ControlName, ControlValue, CapturedAtUtc)
SELECT @p_runId, N'S11', C.ControlName, C.ControlValue, @v_capturedAt
  FROM ControlValueSet AS C …
```

**처방 후보(다음 회차에서 사전 선언 후 착수)**: `ReadInsert` 가 `ControlName` 열을 **같은 문장 CTE 의 `BinaryQueryExpression`(UNION ALL) 가지마다** 풀게 한다 — 가지마다 해당 위치가 리터럴이면 이름, 하나라도 아니면 「모름」 유지. 합격선: ① B20 1 회차 S11·S18 이 발화(교집합 0 변이에서) ② 「모름」 12 의 모양 전수 분류 뒤 몇이 「앎」이 되는가 ③ 되돌림 — 새 가지를 빼면 ①이 조용해진다 ④ 거부된 시도·배송본 오탐 0 ⑤ **⑤(교집합이 비었을 때만)는 그대로 둔다** — B20 실물은 교집합 1 이라 이 처방으로도 안 잡힌다. 교집합 1 을 잡으려면 「부분 겹침」 규칙을 따로 사전 선언해야 한다(정당한 부분 비교와 가르는 오라클이 필요하다).
