## 0. 대장이 적어 둔 전제

## 1. 조건 ① 재료 — 넉넉하다

표의 실제 헤더 이름은 「원천 표현식 (SET)」이 아니라 **「원천 데이터 (Mapping)」** 이다
(대장의 표기가 UPDATE 절 이름을 잘못 옮겼다). 헤더 이름으로 칸을 찾아 세면:

```
명세서 31 · INSERT 절 24 · 표 22 · 행 583 · 원천칸 있는 행 582
  현행 토큰 어휘로 판별 토큰이 나오는 행 138 · 토큰 0 행 444
```

T22(재료 2)·G05(재료 1)와 달리 **재료로는 막히지 않는다.**

## 3. ★ 조건 ③ 「그 검사가 그 자를 쓰기는 하는가」 — **여기서 걸렸다**

T21 의 결함 자리는 `STAT_PGCOLLECT` 의 INSERT 매핑 세 행이다.

| 명세서가 확정한 원천 | 단계(`Batch1/S15`)가 쓴 것 |
| :--- | :--- |
| `LOWER(TBL1.CLIENTID)` | `TBL1.CLIENTID` (L68 · 외부 SELECT) |
| `LOWER(TBL1.PGNAME)` | `TBL1.PGNAME` (L69) |
| `LOWER(TBL1.MALLID)` | `TBL1.MALLID` (L147 · 외부 GROUP BY) |

**실측 1 — 현행 어휘로는 토큰이 0 이다.** 판별 토큰 넷(인용 리터럴 ≥2자 · `UF_` · 두 자리
이상 수 · 별칭.컬럼) 중 어느 것도 안 나온다. 별칭.컬럼 정규식이 `[A-Za-z]\.` 라
**한 글자 별칭만** 인정하는데 여기 별칭은 `TBL1`(네 글자)이다. 13 행 전체에서 토큰이
나오는 것은 3 행(`1.1`·`1.1`·`WOWCOIN` 계열)뿐이고 **세 결함 행은 전부 토큰 0 → 침묵.**

**실측 2 — 어휘를 넓혀도 여전히 침묵한다.** 다글자 별칭과 함수 이름을 토큰으로 인정한다고
가정하고(`LOWER` · `TBL1.CLIENTID`) 단계 본문을 대조했다:

```
CLIENTID   LOWER=있다 · TBL1.CLIENTID=있다
PGNAME     LOWER=있다 · TBL1.PGNAME=있다
MALLID     LOWER=있다 · TBL1.MALLID=있다      → 전부 「있다」 = 침묵
```

**같은 문서 안에 정상 자리와 결함 자리가 함께 있기 때문이다.** 세 UNION 분기는
`LOWER(CLIENTID) AS CLIENTID`(L87~89·L114~116·L133~135)로 **제대로 소문자화하고**,
빠진 것은 **바깥 SELECT·GROUP BY 의 한 겹**이다.

> **이 검사의 자는 「문서 전역 토큰 멤버십」이고, T21 의 결함은 「위치」다.**
> 어휘를 아무리 넓혀도 위치를 못 가린다. `K¹`(판별자 확장)로 닿는 자리가 아니다.

T21 을 닫으려면 단계 SQL 을 파싱해 **최상위 SELECT 의 투영**과 매핑 표를 자리로 맞대야 한다 —
`K¹` 이 아니라 새 구조 검사이고, 크기가 T22·N5 와 다른 급이다.

## 5. 분류를 고친다 — T21 은 `K¹` 이 아니다

`K¹` 의 정의는 「재료는 이미 있고 **검사가 그 칸을 안 볼 뿐**」이다. T21 은 재료도 있고
관할도 닿는데 **자가 그 축(위치)을 원리적으로 못 본다.**

그리고 **결함 등급이 판정을 굳힌다.** 원 감사(2026-08-24)가 이 건에 직접 적었다 —
「`LOWER` 는 멱등이고 세 UNION 분기가 모두 이미 소문자화하므로 삽입 값과 그룹 경계는
동일하다. **결과 금액·행 집합에는 영향이 없고** 명세서 매핑 표와 단계 SQL 의 문자열 대조가
어긋나는 **표기·추적성 결함**이다」(🟡).

**결과 영향 0 의 🟡 하나를 위해 새 구조 검사를 세우는 것은 값 대비 위험이 나쁘다.**
`K¹` → **`N`(기록만)** 으로 내린다. 셈: `K¹` 1 → **0** · `N` 5 → **6**.

**다시 집을 근거는 「`LOWER`」가 아니라 「최상위 투영 대 매핑 표를 자리로 맞대는 검사」가
다른 이유로 설 때다.** 그 검사가 서면 T21 은 공짜로 딸려 온다.

## 7. 이 판독이 보증하지 않는 것

- **INSERT 매핑 표 재료 자체를 기각한 것이 아니다.** 분류표
  (`2026-09-06-결함-강제수단-분류표.md` §4)의 `S03 #2-4`(`CAST(… AS INT)` 누락)가
  같은 표를 오라클로 요구하며 「추출기가 없다」로 막혀 있다. **그 항목은 자가 다르다**
  (위치가 아니라 존재를 본다) — 이 판독의 결론을 그 항목에 옮기지 마라.
- **토큰 어휘의 「한 글자 별칭」 제약은 여기서 고치지 않았다.** 같은 제약이 분류표 §4 의
  `S07`(두 글자 `BB.` → 토큰 0)에도 걸려 있다. 별건이고 그쪽은 값이 있을 수 있다.
- 조건 ⑥(없앴을 때로 잰다)은 **돌리지 않았다** — 만든 것이 없다.
