# T02 금액형 지역 변수 보존 검사 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 명세서가 금액형·초기값으로 확정한 지역 변수를 채우는 단계 SQL의 집계 투영이 타입 표기와 NULL 방어를 보존하는지 보는 L1 검사를 더한다.

**Architecture:** 오라클은 명세서의 `### 지역 변수 (기계 확정 — 수정 금지)` 표다. 추출기가 이미 그 표를 읽고 있으므로 `초기값` 칸 하나만 더 읽으면 재료가 선다. 검사는 ScriptDom으로 **원문 펜스**를 파싱해 별칭이 변수 어근과 일치하는 `SELECT` 투영을 찾고, **그 투영식 부분 트리만** 훑어 `CAST`/`CONVERT`와 `ISNULL`/`COALESCE`를 본다. 별도로, 표를 가져야 하는 SP를 못박은 명부와 대조해 표가 **사라지면** 발화한다.

**Tech Stack:** C# / .NET · xUnit · `Microsoft.SqlServer.TransactSql.ScriptDom` (`TSql160Parser`, `TSqlFragmentVisitor`)

**Spec:** `docs/superpowers/specs/2026-09-05-T02-금액변수-보존검사-설계.md`

### ⚠ 이 태스크의 핵심 함정 — 실물이 보여준 것

S09의 그 문장에는 `ISNULL`이 **있다.** 다만 투영이 아니라 술어다.

```sql
SELECT SUM(A.CLTotal) AS PostChkAmt1      -- 투영: 방어 없음  ← 결함
FROM …
WHERE ISNULL(B.TaxFGBill, 2) = 1          -- 술어: ISNULL 있음 ← 무관
```

`MechanicalValidator.cs`의 `DuplicateProjectionProbe` 바로 아래에 둔다.

```csharp
        /// <summary>
        /// 별칭이 주어진 어근과 일치하는 `SELECT` 투영을 찾아, **그 투영식 부분
        /// 트리만** 훑어 방어 유무를 낸다.
        ///
        /// [왜 문장 전체를 안 보는가 - 실물]
        /// `output/Jobs/POQSettleBatch1/agent/steps/S09.md:169`의 결함 문장은
        /// `WHERE ISNULL(B.TaxFGBill, 2) = 1`을 갖는다. 문장 전체에서 `ISNULL`을
        /// 세면 **술어의 것이 투영의 방어로 오인되어 거짓 통과한다.**
        /// 그래서 정규식이 아니라 파스 트리를 쓰고, 부분 트리를 갈라 본다.
        /// </summary>
        private sealed class MoneyProjectionProbe : TSqlFragmentVisitor
        {
            private readonly IReadOnlyDictionary<string, string> _rootToVariable;

            public MoneyProjectionProbe(IReadOnlyDictionary<string, string> rootToVariable) =>
                _rootToVariable = rootToVariable;

            /// (변수명, 타입 표기 있음, NULL 방어 있음)
            public List<(string Variable, bool HasTypeCast, bool HasNullGuard)> Aggregates { get; } = new();

            public override void Visit(SelectScalarExpression node)
            {
                var alias = node.ColumnName?.Value;
                if (string.IsNullOrEmpty(alias)) return;
                if (!_rootToVariable.TryGetValue(alias, out var variable)) return;

                var scan = new ProjectionGuardScan();
                node.Expression.Accept(scan);

                // 집계가 아니면 묻지 않는다 - 상수 대입(`@v_valIncVat = 1.1`)이
                // 여기서 걸러진다. 설계서 §4-4.
                if (!scan.HasAggregate) return;

                Aggregates.Add((variable, scan.HasTypeCast, scan.HasNullGuard));
            }
        }

        /// <summary>
        /// 한 투영식 부분 트리 안의 집계·타입 표기·NULL 방어를 모은다.
        /// `Visit`(ExplicitVisit 아님)이라 중첩된 호출도 함께 방문된다.
        /// </summary>
        private sealed class ProjectionGuardScan : TSqlFragmentVisitor
        {
            private static readonly HashSet<string> AggregateNames =
                new(StringComparer.OrdinalIgnoreCase) { "SUM", "AVG", "MIN", "MAX", "COUNT", "COUNT_BIG" };

            public bool HasAggregate { get; private set; }
            public bool HasTypeCast { get; private set; }
            public bool HasNullGuard { get; private set; }

            public override void Visit(FunctionCall node)
            {
                var name = node.FunctionName?.Value ?? string.Empty;
                if (AggregateNames.Contains(name)) HasAggregate = true;
                if (name.Equals("ISNULL", StringComparison.OrdinalIgnoreCase)) HasNullGuard = true;
            }

            public override void Visit(CastCall node) => HasTypeCast = true;
            public override void Visit(ConvertCall node) => HasTypeCast = true;
            public override void Visit(CoalesceExpression node) => HasNullGuard = true;
        }
```

```csharp
            @"\b(MONEY|SMALLMONEY|DECIMAL|NUMERIC|FLOAT|REAL)\b",
            RegexOptions.Compiled | RegexOptions.IgnoreCase);

        /// <summary>
        /// 명세서가 **금액형이고 초기값이 있는** 것으로 확정한 지역 변수를 채우는
        /// 집계 투영이 타입 표기와 NULL 방어를 보존하는지 본다.
        ///
        /// [무엇을 막는가 - 축 B 감사 T02(🔴)]
        /// 원본 `dbo.UP_UTIL_SETTLE_PROC_ETC:116`은
        /// `ISNULL(SUM(CAST(CLTotal AS MONEY)), 0)`인데 단계는 `SUM(A.CLTotal)`만 남겼다.
        /// 원저자가 `CAST`를 **명시적으로** 썼다는 것은 원천 컬럼이 `MONEY`가 아니라는
        /// 뜻이고, 캐스트가 없으면 소수부가 절삭된다. 그리고 `ISNULL`이 없으면 무결과일 때
        /// `NULL`이 되는데 대사가 `<>`라 비교가 `UNKNOWN`이 되어 **분기가 아예 안 탄다** —
        /// 불일치가 보고되지 않고 지나간다(오류 코드 `-3`의 자리).
        ///
        /// [왜 어근 접미 일치인가]
        /// 이름이 세 층에 살아남는다: 명세서 `@v_intPostChkAmt1` · 의사코드
        /// `vPostChkAmt1` · 단계 SQL 별칭 `PostChkAmt1`. 접미로 붙이면 헝가리 접두
        /// 목록(`@v_int`·`@v_str`·`@v_val`)에 기대지 않는다. **그러므로 이 검사는
        /// 서수 앵커를 쓰지 않고, 검사 B의 도달률 상한과 무관하다.**
        /// </summary>
        private static void CheckMoneyVariableProjectionGuards(
            IReadOnlyList<SpecStatementFacts> facts,
            string stepMarkdown,
            BatchStepPlan step,
            StepValidationResult result)
        {
            var variables = facts.SelectMany(f => f.LocalVariables)
                .Where(v => !v.IsSystemValue
                    && MoneyTypePattern.IsMatch(v.TypeOrKind)
                    && !string.IsNullOrWhiteSpace(v.InitialValue))
                .DistinctBy(v => v.Name, StringComparer.OrdinalIgnoreCase)
                .ToList();
            if (variables.Count == 0) return;

            // 어근 = `@` 를 뗀 이름. 별칭이 그 어근의 **접미**인지로 붙인다.
            // 사전은 별칭 → 변수명이고, 별칭 후보는 어근 자신과 그 접미들이다.
            var rootToVariable = new Dictionary<string, string>(StringComparer.OrdinalIgnoreCase);
            foreach (var v in variables)
            {
                var bare = v.Name.TrimStart('@');
                for (var i = 0; i < bare.Length; i++)
                {
                    // 접미가 두 글자 미만이면 우연히 겹친다. 그리고 이미 다른 변수가
                    // 가져간 접미는 **양쪽 다 버린다** - 어느 변수의 것인지 모르면
                    // 침묵하는 것이 이 저장소의 규약이다.
                    var suffix = bare[i..];
                    if (suffix.Length < 3) break;
                    if (rootToVariable.TryGetValue(suffix, out var owner))
                    {
                        if (!string.Equals(owner, v.Name, StringComparison.OrdinalIgnoreCase))
                            rootToVariable[suffix] = string.Empty;
                        continue;
                    }
                    rootToVariable[suffix] = v.Name;
                }
            }
            foreach (var ambiguous in rootToVariable.Where(kv => kv.Value.Length == 0).Select(kv => kv.Key).ToList())
                rootToVariable.Remove(ambiguous);

            var byName = variables.ToDictionary(v => v.Name, StringComparer.OrdinalIgnoreCase);
            var reported = new HashSet<string>(StringComparer.OrdinalIgnoreCase);

            // [왜 CleanedSqlFences를 쓰지 않는가]
            // 그 헬퍼는 문자열 리터럴을 공백으로 지워 **파서에 먹일 수 없는** 본문을 낸다
            // (실측: 원문 파스 오류 0 대 문자열 지운 판 11). CheckDuplicateProjectionNames와
            // 같은 이유로 원문을 파싱한다.
            foreach (Match fence in Regex.Matches(
                stepMarkdown, @"```sql(?<sql>.*?)```", RegexOptions.IgnoreCase | RegexOptions.Singleline))
            {
                var parser = new TSql160Parser(initialQuotedIdentifiers: true);
                var fragment = parser.Parse(new StringReader(fence.Groups["sql"].Value), out var errors);
                if (fragment == null || (errors != null && errors.Count > 0)) continue;

                var probe = new MoneyProjectionProbe(rootToVariable);
                fragment.Accept(probe);

                foreach (var (name, hasTypeCast, hasNullGuard) in probe.Aggregates)
                {
                    if (hasTypeCast && hasNullGuard) continue;
                    if (!reported.Add(name)) continue;

                    var v = byName[name];
                    var missing = new List<string>();
                    if (!hasTypeCast)
                        missing.Add($"타입 표기(`CAST(… AS {v.TypeOrKind})`)");
                    if (!hasNullGuard)
                        missing.Add($"NULL 방어(`ISNULL(…, {v.InitialValue})`)");

                    result.Errors.Add(
                        $"{step.Code} 섹션에서 `{name}`을(를) 채우는 집계가 {string.Join("과 ", missing)}을(를) " +
                        $"잃었습니다. 명세서 지역 변수 표는 이 변수를 타입 `{v.TypeOrKind}` · " +
                        $"초기값 `{v.InitialValue}`으로 확정합니다 — 원본이 그 둘을 명시적으로 썼습니다. " +
                        "타입 표기가 없으면 원천 타입의 소수부가 절삭되고, NULL 방어가 없으면 무결과일 때 " +
                        "값이 NULL이 되어 이 값을 쓰는 비교가 UNKNOWN이 됩니다(분기가 아예 실행되지 않습니다).");
                }
            }
        }
```
