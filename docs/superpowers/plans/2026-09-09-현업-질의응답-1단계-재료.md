> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 이미 쌓인 `output/**/Spec.md` 코퍼스를 헤딩 절 단위로 색인하고 컬럼·코드값 어휘 다리를 세워, 「이 용어가 어느 절에 있나」를 CLI 로 물을 수 있게 만든다.

**Architecture:** `ReSet.Answers.Core` 를 새로 만들어 `ReSet.Core` 의 `EvidenceQuoteMatcher` · `MarkdownSectionLocator` · `PolicyCorpusLoader` · `ConstantComparisonExtractor` 를 재사용한다. DB 에 붙지 않고 `output/` 을 읽기만 한다. 검색은 외부 의존 없는 순수 .NET BM25 이며 임베딩을 쓰지 않는다.

**Tech Stack:** .NET 10 · C# · xunit 2.9.3 · Xunit.SkippableFact · NSubstitute (기존 `tests/ReSet.Core.Tests` 에 합류)

**Spec:** `docs/superpowers/specs/2026-09-09-현업-질의응답-design.md`

## Global Constraints

- **`output/` 에 쓰지 않는다.** 읽기 전용이다(spec §3-2 ①). 이 계획의 어떤 태스크도 `output/` 아래에 파일을 만들거나 고치지 않는다.
- **DB 에 붙지 않는다**(spec §3-2 ②). 연결 문자열·`Microsoft.Data.SqlClient` 를 `ReSet.Answers.Core` 에 넣지 않는다.
- **`src/ReSet.Cli` 를 건드리지 않는다**(spec §3-1).
- **`PolicyTargetDiscovery` · `PrdTargetDiscovery` 를 고치지 않는다.** 두 클래스는 `output/Procedures` 만 훑도록 의도적으로 좁혀져 있고, 넓히면 §4.10 정책 도출과 §4.14 PRD 도출의 대상 집합이 함께 움직인다. Answers 는 자기 발견기를 따로 갖는다(Task 1).
- **빌드 경고 0.** `dotnet clean && dotnet build 2>&1 | grep -cE "warning CS"` 가 `0` 이어야 한다(AGENTS.md 체크리스트 — 증분 빌드는 기존 경고를 다시 보고하지 않으므로 `clean` 이 필수다).
- **`dotnet test` 실패 0 · 건너뜀 0.**
- **격리 워크트리에서 작업한다**(AGENTS.md 범주 8). 공유 체크아웃의 `bin/`·`obj/` 가 겹쳐 빌드 귀속이 끊긴다. 워크트리에는 `output/` 이 없으므로 심링크한다: `ln -s <메인 저장소>/output output`

## 설계서와 다른 점 하나 (의도된 것)

Spec §3-1 은 프로젝트를 `ReSet.Answers.Core` 와 `ReSet.Answers.Web` 둘로 적었다. **이 계획은 `ReSet.Answers.Cli` 를 하나 더 만든다**(Task 7).

이유: 웹은 4단계 산출물인데, 1단계와 2단계는 그 전에 **돌려 볼 표면**이 있어야 한다. 특히 2단계 끝의 §8-4 E2E — 「모른다」 비율을 재는 자리 — 는 웹 없이 돌아야 한다(spec §10 의 판단 지점이 1과 2 사이에 있다). `ReSet.Cli` 에 붙이는 것은 §3-1 이 금지하므로 작은 콘솔 프로젝트를 따로 둔다. 2·3단계가 이 프로젝트를 이어 쓰고, 4단계의 웹은 별개다.

```csharp
using System;
using System.Collections.Generic;
using System.IO;
using System.Linq;
using ReSet.Core.Services;

namespace ReSet.Answers.Core.Services
{
    /// <summary>
    /// output 아래에서 Spec.md가 있는 객체를 전부 찾는다.
    ///
    /// [왜 PolicyTargetDiscovery를 넓히지 않는가] 그 클래스는 output/Procedures만
    /// 훑도록 의도적으로 좁혀져 있고, 넓히면 정책 도출(§4.10)과 PRD 도출(§4.14)의
    /// 대상 집합이 함께 움직인다. Answers의 코퍼스는 Functions·External을 포함하므로
    /// (실측 31편 = Procedures 14 + Functions 10 + External 7) 발견기를 따로 둔다.
    /// 돌려주는 기록은 같은 PolicyTarget이다 - PolicyCorpusLoader가 그것을 받는다.
    ///
    /// [왜 재귀인가] External은 output/External/{DB}/Functions/{객체}/docs/Spec.md로
    /// 한 단계 더 깊다. 갈래마다 깊이를 손으로 적으면 갈래가 늘 때 조용히 빠진다.
    /// </summary>
    public static class AnswerCorpusDiscovery
    {
        public static IReadOnlyList<PolicyTarget> Find(string outputRoot)
        {
            if (string.IsNullOrEmpty(outputRoot) || !Directory.Exists(outputRoot))
            {
                return Array.Empty<PolicyTarget>();
            }

            var targets = new List<PolicyTarget>();
            foreach (var docs in Directory.EnumerateDirectories(outputRoot, "docs", SearchOption.AllDirectories))
            {
                if (!File.Exists(Path.Combine(docs, OutputPathResolver.SpecFileNamePublic)))
                {
                    continue;
                }

                var objectDirectory = Path.GetDirectoryName(docs);
                if (objectDirectory is null)
                {
                    continue;
                }

                targets.Add(new PolicyTarget(
                    Path.GetFileName(objectDirectory),
                    docs,
                    Path.Combine(objectDirectory, "raw", "metadata.json")));
            }

            return targets.OrderBy(t => t.Label, StringComparer.Ordinal).ToList();
        }
    }
}
```

```csharp
using System;
using ReSet.Core.Services;

namespace ReSet.Answers.Core.Services
{
    /// <summary>
    /// Spec.md 머리말(`---` 사이)에서 검증 종료 상태를 읽는다.
    ///
    /// 값을 열거형으로 옮기지 않고 문자열 그대로 나른다 - 이 리더의 오라클은 산출물의
    /// 표기이고, 열거형으로 좁히면 표기가 늘 때 조용히 「미상」으로 떨어진다.
    /// </summary>
    public static class SpecFrontMatterReader
    {
        public const string Unknown = "미상";

        private const string Key = "검증 상태:";

        public static string ReadVerificationStatus(string? specMarkdown)
        {
            var lines = MarkdownSectionLocator.SplitLines(specMarkdown);
            if (lines.Count == 0 || lines[0].Trim() != "---")
            {
                return Unknown;
            }

            for (var i = 1; i < lines.Count; i++)
            {
                var line = lines[i].Trim();
                if (line == "---")
                {
                    break;
                }

                if (!line.StartsWith(Key, StringComparison.Ordinal))
                {
                    continue;
                }

                var value = line[Key.Length..];
                var comment = value.IndexOf('#');
                if (comment >= 0)
                {
                    value = value[..comment];
                }

                value = value.Trim();
                return value.Length == 0 ? Unknown : value;
            }

            return Unknown;
        }
    }
}
```

```csharp
using System;
using System.Collections.Generic;
using ReSet.Answers.Core.Models;
using ReSet.Core.Services;

namespace ReSet.Answers.Core.Services
{
    /// <summary>
    /// 명세서 하나를 헤딩 절 목록으로 가른다.
    ///
    /// [왜 EvidenceQuoteMatcher.ExtractSectionBody가 아닌가] 그 메서드는 경계 접두를
    /// "## "로 하드코딩한다. 이 코퍼스의 기계 확정 절은 전부 "### "이고(610절 중 241),
    /// "### "를 경계로 넘기면 다음 H2를 건너뛰고 그 아래 H3까지 한 절이 삼킨다.
    /// 그래서 한 번의 순회로 모든 헤딩을 모은다. ExtractSectionBody는 2단계의 근거
    /// 대조에서 원래 용도대로 쓴다.
    ///
    /// [부모가 자식을 다시 담지 않는다] H2의 본문은 첫 H3 직전까지다. 자식 본문을
    /// 부모가 겹쳐 담으면 BM25가 같은 글을 두 번 세어 부모 절이 부당하게 상위로 온다.
    /// </summary>
    public static class SpecSectionSplitter
    {
        private const string MachineConfirmedMarker = "기계 확정";

        public static IReadOnlyList<SpecSection> Split(string objectLabel, string? specMarkdown)
        {
            var lines = MarkdownSectionLocator.SplitLines(specMarkdown);
            var inFence = MarkdownSectionLocator.ComputeFenceFlags(lines);
            var status = SpecFrontMatterReader.ReadVerificationStatus(specMarkdown);

            var headingIndexes = new List<int>();
            for (var i = FirstBodyLine(lines); i < lines.Count; i++)
            {
                if (!inFence[i] && IsHeading(lines[i]))
                {
                    headingIndexes.Add(i);
                }
            }

            var sections = new List<SpecSection>();
            var occurrences = new Dictionary<string, int>(StringComparer.Ordinal);

            for (var h = 0; h < headingIndexes.Count; h++)
            {
                var start = headingIndexes[h];
                var end = h + 1 < headingIndexes.Count ? headingIndexes[h + 1] : lines.Count;

                var headingLine = lines[start].Trim();
                var headingText = EvidenceQuoteMatcher.NormalizeHeading(headingLine);
                var occurrence = occurrences.TryGetValue(headingText, out var seen) ? seen : 0;
                occurrences[headingText] = occurrence + 1;

                sections.Add(new SpecSection(
                    objectLabel,
                    headingLine,
                    headingText,
                    occurrence,
                    string.Join("\n", lines.GetRange(start + 1, end - start - 1)).Trim(),
                    headingText.Contains(MachineConfirmedMarker, StringComparison.Ordinal),
                    status));
            }

            return sections;
        }

        /// <summary>머리말(`---` 사이)은 헤딩 수집에서 뺀다.</summary>
        private static int FirstBodyLine(IReadOnlyList<string> lines)
        {
            if (lines.Count == 0 || lines[0].Trim() != "---")
            {
                return 0;
            }

            for (var i = 1; i < lines.Count; i++)
            {
                if (lines[i].Trim() == "---")
                {
                    return i + 1;
                }
            }

            return 0;
        }

        /// <summary>
        /// H2와 H3만 절로 삼는다. "#### x"는 네 번째 글자가 공백이 아니라 걸리지 않는다.
        /// </summary>
        private static bool IsHeading(string line)
        {
            var trimmed = line.TrimStart();
            return trimmed.StartsWith("## ", StringComparison.Ordinal)
                   || trimmed.StartsWith("### ", StringComparison.Ordinal);
        }
    }
}
```

```csharp
using System;
using System.Collections.Generic;
using ReSet.Answers.Core.Models;
using ReSet.Core.Models;

namespace ReSet.Answers.Core.Services
{
    /// <summary>
    /// metadata.json의 컬럼·테이블 설명을 「현업 말 → 코드 대상」 역방향으로 뒤집는다.
    ///
    /// [왜 이것이 어휘 다리의 중심인가 - 2026-09-09 실측] 코퍼스의 고유 컬럼 1,550개 중
    /// 1,548개(99%)에 한국어 업무 설명이 붙어 있고 AI 추론 보완은 0건이다 - 전부 사람이
    /// DB에 적은 MS_Description이다. 「고객사 지급일자」·「PG 회수일자」처럼 현업이 쓰는
    /// 말 그대로라, 다리를 새로 지을 필요가 없고 방향만 뒤집으면 된다.
    /// </summary>
    public static class ColumnGlossaryBuilder
    {
        public static IReadOnlyList<GlossaryEntry> Build(IReadOnlyList<DependencyInfo> dependencies)
        {
            var seen = new HashSet<(string, string)>();
            var entries = new List<GlossaryEntry>();

            void Add(string? term, string canonical)
            {
                if (string.IsNullOrWhiteSpace(term) || !seen.Add((term.Trim(), canonical)))
                {
                    return;
                }

                entries.Add(new GlossaryEntry(term.Trim(), canonical, GlossaryLayer.Column));
            }

            foreach (var dependency in dependencies)
            {
                var table = Qualify(dependency);
                Add(dependency.Description, table);

                foreach (var column in dependency.Columns)
                {
                    Add(column.Description, $"{table}.{column.ColumnName}");
                }
            }

            return entries;
        }

        /// <summary>
        /// Database가 없는 의존성이 있다(같은 DB 안의 객체는 null로 남는다). 그 자리에
        /// 빈 문자열을 이어 붙이면 선행 점이 생겨 canonical이 갈라지므로 생략한다.
        /// </summary>
        private static string Qualify(DependencyInfo dependency) =>
            string.IsNullOrWhiteSpace(dependency.Database)
                ? $"{dependency.Schema}.{dependency.Name}"
                : $"{dependency.Database}.{dependency.Schema}.{dependency.Name}";
    }
}
```

```csharp
        public static IReadOnlyList<GlossaryEntry> Build(string? ddlText, string? specMarkdown)
        {
            var normalizedSpec = EvidenceQuoteMatcher.NormalizeForQuoteMatch(specMarkdown ?? string.Empty);

            var seen = new HashSet<(string, string)>();
            var entries = new List<GlossaryEntry>();

            foreach (var comparison in ConstantComparisonExtractor.Extract(ddlText))
            {
                var value = comparison.Value?.Trim();
                if (string.IsNullOrEmpty(value))
                {
                    continue;
                }

                var needle = EvidenceQuoteMatcher.NormalizeForQuoteMatch(value);
                if (needle.Length == 0 || !normalizedSpec.Contains(needle, StringComparison.Ordinal))
                {
                    continue;
                }

                var column = string.IsNullOrWhiteSpace(comparison.Column)
                    ? UnknownColumn
                    : comparison.Column.Trim();

                if (seen.Add((value, column)))
                {
                    entries.Add(new GlossaryEntry(value, column, GlossaryLayer.Codebook));
                }
            }

            return entries;
        }
    }
```

```csharp
using System;
using System.Collections.Generic;
using System.Text;

namespace ReSet.Answers.Core.Services
{
    /// <summary>
    /// 한국어 산문과 SQL 식별자가 섞인 글을 검색 토큰으로 가른다.
    ///
    /// [왜 음절 2-그램인가] 형태소 분석기를 붙이지 않는다 - 외부 의존이 늘고, 이 코퍼스
    /// 크기(610절)에는 과하다. 대신 한글 덩어리를 덩어리 자체와 음절 2-그램으로 함께
    /// 내면 조사와 복합어를 형태소 없이 넘긴다: 「지급일자」로 색인된 절이 「지급일」
    /// 질의에도 걸린다.
    ///
    /// [식별자] 영숫자 덩어리는 구두점에서 갈라 소문자로 낸다 - TSettleMst.OutYMD가
    /// tsettlemst와 outymd 둘이 된다.
    /// </summary>
    public static class KoreanTokenizer
    {
        public static IReadOnlyList<string> Tokenize(string? text)
        {
            var tokens = new List<string>();
            if (string.IsNullOrEmpty(text))
            {
                return tokens;
            }

            var buffer = new StringBuilder();
            var bufferIsHangul = false;

            void Flush()
            {
                if (buffer.Length == 0)
                {
                    return;
                }

                var chunk = buffer.ToString();
                if (bufferIsHangul)
                {
                    tokens.Add(chunk);
                    for (var i = 0; i + 1 < chunk.Length; i++)
                    {
                        tokens.Add(chunk.Substring(i, 2));
                    }
                }
                else
                {
                    tokens.Add(chunk.ToLowerInvariant());
                }

                buffer.Clear();
            }

            foreach (var ch in text)
            {
                var isHangul = ch is >= '가' and <= '힣';
                var isLatin = !isHangul && char.IsLetterOrDigit(ch);

                if (!isHangul && !isLatin)
                {
                    Flush();
                    continue;
                }

                if (buffer.Length > 0 && isHangul != bufferIsHangul)
                {
                    Flush();
                }

                bufferIsHangul = isHangul;
                buffer.Append(ch);
            }

            Flush();
            return tokens;
        }
    }
}
```

```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using ReSet.Answers.Core.Models;

namespace ReSet.Answers.Core.Services
{
    /// <summary>검색 결과 한 건 - 절과 그 점수.</summary>
    public sealed record Bm25Hit(SpecSection Section, double Score);

    /// <summary>
    /// 헤딩 절에 대한 BM25 검색. 외부 의존이 없다.
    ///
    /// [왜 임베딩이 아닌가] 610절이면 BM25로 충분하고, 임베딩은 외부 호출·비용·재색인을
    /// 새로 지운다. 무엇보다 이 프로젝트는 큰 프롬프트가 비싸다는 것이 실측돼 있다
    /// (hy4는 12K 토큰을 넘으면 캐시 적중 0%). 임베딩이 필요해지는 것은 「모른다」가
    /// 많은데 원인이 검색 실패로 판명될 때이고, 그때도 현업 용어 사전을 채우는 것이 싸다.
    ///
    /// [동점 처리] 점수가 같으면 객체·헤딩 사전순으로 고정한다. 순서가 실행마다 흔들리면
    /// 2단계의 G2(근거가 이번 검색이 준 절 안인가)가 재현 불가능해진다.
    /// </summary>
    public sealed class Bm25Index
    {
        private const double K1 = 1.2;
        private const double B = 0.75;

        private readonly IReadOnlyList<SpecSection> _sections;
        private readonly List<Dictionary<string, int>> _termFrequencies = new();
        private readonly Dictionary<string, int> _documentFrequency = new(StringComparer.Ordinal);
        private readonly List<int> _lengths = new();
        private readonly double _averageLength;

        public Bm25Index(IReadOnlyList<SpecSection> sections)
        {
            _sections = sections;

            foreach (var section in sections)
            {
                var tokens = KoreanTokenizer.Tokenize(section.HeadingText + "\n" + section.Body);
                var frequencies = new Dictionary<string, int>(StringComparer.Ordinal);

                foreach (var token in tokens)
                {
                    frequencies[token] = frequencies.TryGetValue(token, out var n) ? n + 1 : 1;
                }

                _termFrequencies.Add(frequencies);
                _lengths.Add(tokens.Count);

                foreach (var term in frequencies.Keys)
                {
                    _documentFrequency[term] =
                        _documentFrequency.TryGetValue(term, out var d) ? d + 1 : 1;
                }
            }

            _averageLength = _lengths.Count == 0 ? 0 : _lengths.Average();
        }

        public IReadOnlyList<Bm25Hit> Search(IReadOnlyList<string> queryTokens, int topN)
        {
            var distinct = queryTokens.Distinct(StringComparer.Ordinal).ToList();
            var hits = new List<Bm25Hit>();

            for (var i = 0; i < _sections.Count; i++)
            {
                var score = 0.0;

                foreach (var term in distinct)
                {
                    if (!_documentFrequency.TryGetValue(term, out var df)
                        || !_termFrequencies[i].TryGetValue(term, out var tf))
                    {
                        continue;
                    }

                    var idf = Math.Log(1 + ((_sections.Count - df + 0.5) / (df + 0.5)));
                    var normalized = _averageLength == 0 ? 1 : _lengths[i] / _averageLength;
                    score += idf * (tf * (K1 + 1)) / (tf + (K1 * (1 - B + (B * normalized))));
                }

                if (score > 0)
                {
                    hits.Add(new Bm25Hit(_sections[i], score));
                }
            }

            return hits
                .OrderByDescending(h => h.Score)
                .ThenBy(h => h.Section.ObjectLabel, StringComparer.Ordinal)
                .ThenBy(h => h.Section.HeadingText, StringComparer.Ordinal)
                .ThenBy(h => h.Section.Occurrence)
                .Take(topN)
                .ToList();
        }
    }
```

```csharp
using System.IO;

using ReSet.Answers.Core.Models;
```

```csharp
namespace ReSet.Answers.Core.Services
{
    /// <summary>
    /// answers/glossary.md - 사람이 소유하는 현업 용어 사전을 읽는다.
    ///
    /// [왜 사람이 소유하는가] 「익일정산」·「미수」 같은 말은 코드에도 컬럼 설명에도
    /// 없다. settlement-process.md와 같은 패턴이다. 2단계의 「모른다」가 미해결 용어를
    /// 이 파일의 대기열로 쌓고 사람이 채운다 - 그 루프가 도달률을 올린다.
    ///
    /// 형식은 두 칸 마크다운 표다: | 현업 용어 | 대응 |
    /// </summary>
    public static class HumanGlossaryReader
    {
        public const string FileName = "glossary.md";

        public static IReadOnlyList<GlossaryEntry> Read(string glossaryPath)
        {
            if (!File.Exists(glossaryPath))
            {
                return Array.Empty<GlossaryEntry>();
            }

            var entries = new List<GlossaryEntry>();
            var seen = new HashSet<(string, string)>();

            foreach (var line in MarkdownSectionLocator.SplitLines(File.ReadAllText(glossaryPath)))
            {
                var trimmed = line.Trim();
                if (!trimmed.StartsWith('|'))
                {
                    continue;
                }

                var cells = trimmed.Trim('|').Split('|').Select(c => c.Trim()).ToList();
                if (cells.Count < 2)
                {
                    continue;
                }

                var term = cells[0];
                var canonical = cells[1];

                // 제목 행과 :--- 구분 행을 거른다.
                if (term.Length == 0 || canonical.Length == 0
                    || term == "현업 용어" || canonical.All(c => c is '-' or ':'))
                {
                    continue;
                }

                if (seen.Add((term, canonical)))
                {
                    entries.Add(new GlossaryEntry(term, canonical, GlossaryLayer.Human));
                }
            }

            return entries;
        }
    }
}
```

```csharp
using System;
using System.Collections.Generic;
using System.IO;
using System.Linq;
using ReSet.Answers.Core.Models;
using ReSet.Core.Services;

namespace ReSet.Answers.Core.Services
{
    /// <summary>
    /// output 코퍼스를 읽어 절 색인과 어휘 다리를 조립한다.
    ///
    /// [output에 쓰지 않는다] 이 경로는 읽기 전용이다. Answers의 상태는 answers/ 아래에만
    /// 산다 - output은 gitignore 대상이고 재분석으로 통째로 갈아엎히는 자리다.
    ///
    /// [DB에 붙지 않는다] PRD 도출(§4.14)·정책 도출(§4.10)과 같은 판단이다.
    /// 그래서 코드값 사전의 우변(업무 의미)은 여기서 채워지지 않는다.
    /// </summary>
    public static class AnswerIndexBuilder
    {
        public static (AnswerIndex Index, AnswerIndexStats Stats) Build(
            string outputRoot, string answersRoot)
        {
            var sections = new List<SpecSection>();
            var columnTerms = new List<GlossaryEntry>();
            var codebookTerms = new List<GlossaryEntry>();

            foreach (var target in AnswerCorpusDiscovery.Find(outputRoot))
            {
                var source = PolicyCorpusLoader.Load(target);
                if (source is null)
                {
                    continue;
                }

                sections.AddRange(SpecSectionSplitter.Split(target.Label, source.SpecMarkdown));
                columnTerms.AddRange(ColumnGlossaryBuilder.Build(source.Dependencies));
                codebookTerms.AddRange(
                    CodebookLeftSideBuilder.Build(source.DdlText, source.SpecMarkdown));
            }

            var humanTerms = HumanGlossaryReader.Read(
                Path.Combine(answersRoot, HumanGlossaryReader.FileName));

            var glossary = Deduplicate(columnTerms)
                .Concat(Deduplicate(codebookTerms))
                .Concat(humanTerms)
                .ToList();

            var index = new AnswerIndex(sections, glossary, new Bm25Index(sections));

            var stats = new AnswerIndexStats(
                sections.Count,
                sections.Count(s => s.IsMachineConfirmed),
                sections.Count(s => !s.IsMachineConfirmed),
                glossary.Count(e => e.Layer == GlossaryLayer.Column),
                glossary.Count(e => e.Layer == GlossaryLayer.Codebook),
                glossary.Count(e => e.Layer == GlossaryLayer.Human));

            return (index, stats);
        }

        /// <summary>
        /// 질문 토큰에 어휘가 가리키는 대상의 토큰을 더한다. 「고객사 지급일자」로 물으면
        /// outymd도 함께 찾게 하는 것이 어휘 다리가 하는 일이다.
        /// </summary>
        /// <returns>확장된 질의 토큰과, 질문 안에서 실제로 걸린 어휘 용어들.</returns>
        public static (IReadOnlyList<string> Tokens, IReadOnlyList<string> MatchedTerms) ExpandQuery(
            AnswerIndex index, string question)
        {
            var tokens = KoreanTokenizer.Tokenize(question).ToList();
            var matched = new List<string>();
            var normalizedQuestion = EvidenceQuoteMatcher.NormalizeForQuoteMatch(question);

            foreach (var entry in index.Glossary)
            {
                var needle = EvidenceQuoteMatcher.NormalizeForQuoteMatch(entry.Term);
                if (needle.Length == 0
                    || !normalizedQuestion.Contains(needle, StringComparison.Ordinal))
                {
                    continue;
                }

                matched.Add(entry.Term);
                tokens.AddRange(KoreanTokenizer.Tokenize(entry.Canonical));
            }

            return (tokens, matched.Distinct(StringComparer.Ordinal).ToList());
        }

        private static IEnumerable<GlossaryEntry> Deduplicate(IEnumerable<GlossaryEntry> entries)
        {
            var seen = new HashSet<(string, string)>();
            foreach (var entry in entries)
            {
                if (seen.Add((entry.Term, entry.Canonical)))
                {
                    yield return entry;
                }
            }
        }
    }
}
```

```csharp
                return 1;
            }

            var (tokens, matched) = AnswerIndexBuilder.ExpandQuery(index, term);

            Console.WriteLine(matched.Count == 0
                ? "걸린 어휘: (없음) — 이 말은 사전 세 층 어디에도 없습니다"
                : "걸린 어휘: " + string.Join(" · ", matched));

            var hits = index.Bm25.Search(tokens, top);
            if (hits.Count == 0)
            {
                Console.WriteLine("찾은 절 없음");
                return 0;
            }

            Console.WriteLine();
            foreach (var hit in hits)
            {
                var kind = hit.Section.IsMachineConfirmed ? "기계확정" : "산문";
                Console.WriteLine(
                    $"{hit.Score,7:F2}  [{kind}] {hit.Section.ObjectLabel} › {hit.Section.HeadingText}");
            }

            return 0;
        }

        private static string? ReadOption(string[] args, string name)
        {
            var at = Array.IndexOf(args, name);
            return at >= 0 && at + 1 < args.Length ? args[at + 1] : null;
        }
    }
}
```
