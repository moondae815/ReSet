## 1. 결함 — 원본이 명시적으로 쓴 방어 둘이 사라졌다

```sql
-- 원본 dbo.UP_UTIL_SETTLE_PROC_ETC (object_definition.sql:32·116·137)
DECLARE @v_intPostChkAmt1  MONEY = 0
SELECT  @v_intPostChkAmt1 = ISNULL(SUM(CAST(CLTotal AS MONEY)), 0)
IF      @v_intPostChkAmt1 <> @v_intPostChkAmt2 BEGIN   -- 대사

-- 후 단계 output/Jobs/POQSettleBatch1/agent/steps/S09.md:169
SELECT SUM(A.CLTotal) AS PostChkAmt1
```

**둘을 잃었다.**

1. **`CAST(… AS MONEY)`** — 원저자가 **명시적으로** 썼다. 즉 `CLTotal`은 `MONEY`가 아니다.
   캐스트가 없으면 원천 타입의 소수부가 절삭돼 두 집계가 다른 자리에서 반올림된다.
2. **`ISNULL(…, 0)`** — 없으면 무결과일 때 `NULL`이 된다. 그리고 대사가 `<>`라
   **한쪽이 `NULL`이면 비교가 `UNKNOWN`이 되어 `IF`가 아예 안 탄다** — 불일치가
   보고되지 않고 조용히 지나간다. 오류 코드 `-3`이 그 자리다(명세서 233행).

`S09.md:181`(`SELECT SUM(CLSettleAmt) AS PostChkAmt2`)이 같은 모양의 짝이다.

## 2. 오라클 — 명세서 지역 변수 표. **다른 둘은 실측으로 기각했다**

| 후보 | 오라클 | 판정 |
| :--- | :--- | :--- |
| **A** 명세서 지역 변수 기계 표 | `데이터 타입` + `초기값` | **채택** |
| B 원본 DDL 재파생 | `DECLARE @v MONEY = 0` | **기각** — 아래 |
| C 자기 일관성(오라클 불필요) | — | **기각** — 아래 |

**C를 기각한 이유는 산출물 자신이다.** 대사 쌍인 `SELECT 5`·`SELECT 6`이 **둘 다** 방어가 없다.
대칭이므로 「한쪽만 다르다」로는 안 걸린다.

**B를 기각한 이유는 신호 밀도다.** 「원본이 쓴 방어가 단계에서 사라졌다」로 부류를 넓히면:

```
                 원본 DDL(전체 SP)   Batch1 단계
ISNULL(                     286          301     ← 늘었다
CAST(                        88          121     ← 늘었다
PROC_ETC 단독 CAST(           2            0     ← 전량 소실
```

**단계가 원본보다 방어를 더 쓴다.** 방어 소실은 계통적 현상이 아니라 **한 자리의 사건**이다.
넓히면 분모 286에 신호 2가 되어 착수 조건 ⑤(오탐이 다수가 아니다)에 걸린다.
**좁은 자리에만 신호가 있고, 그 자리를 명세서 표가 정확히 확정한다.**

**A의 약점은 재료 소멸이다** — T02가 바로 그 사고였다(그 표가 명세서에서 사라졌다).
§3이 그것을 처방한다. 이 처방이 있으면 B의 「재료가 불멸이다」라는 유일한 우위가 상쇄된다.

### 재료 상태 — 절반은 이미 흐른다

`SpecStatementFactsExtractor.ReadLocalVariables`가 이미 표를 읽어
`SpecLocalVariable(Name, TypeOrKind, IsSystemValue)`를 낸다(검사 D가 소비 중).
**`초기값` 칸만 안 읽는다.** 추출기에 한 칸을 더하는 것이 재료 작업의 전부다.

## 3. 침묵을 발화로 — **T02를 만든 실패 모드를 직접 막는다**

T02의 발생 경위는 「명세서에서 표가 사라졌는데 아무도 몰랐다」이다.
검사 D가 18 → 0으로 꺼진 것과 같은 모양이고, 이 저장소가 **세 번째로** 겪는 자리다.

**그러므로 표가 없으면 「통과」가 아니라 「오라클 없음」으로 따로 발화한다.**
이것이 A의 유일한 약점에 대한 처방이고, B를 안 써도 되는 이유다.

## 4. 판별자 — §7이 열어 둔 물음에 답한다

§7의 물음: 「«`CAST`가 있는가» 인지 «타입이 같은가» 인지」. **둘 다 아니다.**

- **「타입이 같은가」** — 못 잰다. 단계는 의사코드라 타입 표기가 없고 그게 결함의 내용이다.
- **「`CAST`가 있는가」** — 오탐한다. `CAST`는 코퍼스에서 88 → 121로 **늘었다**.
  유무만 보면 신호가 없다.
- **채택: 「명세서가 금액형·초기값으로 확정한 변수를 채우는 *집계*가 그 둘을 보존하는가」**

### 절차

1. 명세서 지역 변수 표에서 **금액형**(`MONEY`·`DECIMAL`·`NUMERIC`·`FLOAT`)이고
   **초기값 칸이 비지 않은** 행을 뽑는다.
2. 변수명의 **어근**을 얻는다 — 별칭이 변수명의 **접미**인지로 붙인다
   (`PostChkAmt1` ⊂ `@v_intPostChkAmt1`). **헝가리 접두 목록에 기대지 않는다.**
3. 단계 SQL 펜스에서 그 어근을 **별칭으로 쓰는 `SELECT` 투영**을 찾는다.
4. 그 투영식이 **집계**(`SUM`·`AVG`·`MIN`·`MAX`·`COUNT`)일 때만 본다.
   상수 대입(`@v_valIncVat = 1.1` 두 건)은 여기서 걸러진다.
5. **타입 표기**(`CAST`·`CONVERT`)와 **NULL 방어**(`ISNULL`·`COALESCE`)를 각각 본다.
   없는 쪽을 이름 붙여 발화한다.

### 왜 앵커를 안 쓰는가

이름이 **세 층에 살아남는다**.

```
명세서    @v_intPostChkAmt1 | MONEY | 0
의사코드  vPostChkAmt1 = queryScalar(SQL_CHECK_MST_AMOUNT, …)
단계 SQL  SELECT SUM(A.CLTotal) AS PostChkAmt1
```

접미 일치로 붙으므로 **서수 앵커가 필요 없다.** 그러므로 이 검사는
**검사 B의 도달률 상한(관할 1,413 중 852 = 60.3%)과 무관하다** — 분류 문서 §13 참고.

## 5. 사전 선언 — 착수 전에 못박는다

| 조건 | 값 |
| :--- | :--- |
| ① 행 수 | 금액형 **7행 / 3편**. 그중 **집계로 채워지는 5행**은 전부 `PROC_ETC` |
| ② 도달 가능성 | 별칭 접미 일치. **앵커 불필요** |
| ③ 그 검사가 그 자를 쓰는가 | **안 쓴다** — 앵커 상한과 무관 |
| ④ 발화 예측 | **정확히 2 — `S09.md:169`·`181`** (§7이 「N4와 같은 두 문장」이라 적은 그 둘) |
| ⑤ 오탐 | 분모 5행, 집계 투영 한정 |
| ⑥ 없앴을 때 | 수정을 빼고 다시 재서 그 둘이 사라지는지 본다 |

**되돌림 조건 — 어긋나면 되돌리고 다시 잰다. 숫자를 맞추려고 조건을 손보지 않는다.**

- **발화 0** → 결합이 틀렸다. 어근·별칭 가정을 다시 잰다.
- **발화 > 2** → 초과분을 **전부 열어 본다.** 오탐이 다수면 되돌린다.
- **단위 시험만 녹색이고 코퍼스가 침묵** → 픽스처가 실물보다 단순한 것이다. 되돌린다.
  (이 회차에 그 이유로 두 번 되돌렸다 — 접힘 판별자·T22.)

**측정은 격리 워크트리에서 한다. 코퍼스 재료 넷을 다 걸고 시작한다**(3/3으로 놓친 자리다).
게이트는 실패 0 · 건너뜀 0 · 경고 0이고 통과 수는 게이트가 아니다.

## 7. 이 설계가 보증하지 않는 것

- **코퍼스 방어망이 아니다.** 재료가 5행이고 전부 한 SP에 있다. 그 이상을 주장하지 않는다.
  넓히려면 §2의 실측(286/88)을 다시 보라 — 넓힌 판은 이미 기각됐다.
- **`CLTotal`의 실제 DB 타입을 확인하지 않았다.** 원저자가 `CAST`를 썼다는 사실로
  「`MONEY`가 아니다」를 **추론**했다. 로컬 Docker는 빈 스키마라 실행으로 못 닫는다.
  이 추론이 틀려도 검사는 성립한다(명세서가 확정한 타입을 보존하라는 것이므로).
- **대사 로직 자체는 안 본다.** `<>` 비교가 `NULL`에서 안 타는 것은 이 검사의 발화 사유이지
  검사 대상이 아니다.
- **N4의 나머지가 이 검사로 전부 닫히는지 재지 않았다.** §7이 「같은 두 문장」이라 적었고
  그 둘은 덮이지만, N4 항목 전체의 소멸은 발화를 보고 판정한다.
